# 終盤を迎える状態と、その後の勝敗：計算前計画

2026-10-04。ユーザー承諾の次の問いを固定する。前の到達比較で反例となった2013・2018・2019・2024年、とくに2019年が着想の入口。未知データでの検証ではない。計画をコミットしてから計算する。

## 対象と定義

- 入力・年計照合はmatched_comeback.pyと同じ固定CSV（SHA-256 `0e98d6ce001eaca565378814a551d8b694e66dff7f4ef856d4e636e39bb87beb`）およびseason Git blob `fd76d410b7d8d9438237abc751820dcbf95c05e4`。
- 主対象2013〜2025、2020除外。2020込みも参考で保持。全球団156球団年を作り、中日は同年度セ他5球団の合算と比較。交流戦・引分を含む。2026対象外。
- 主切点7回、感度6回。両チームが切点回を実施し、次回表がある試合のみ。前研究と同じ継続条件・未実施回の扱い。除外件数を記録する。
- 自軍得点−相手得点の正確な点差とホーム/ビジター別に集計。表示分類は3点以上ビハインド／2点ビハインド／1点ビハインド／同点／1点リード／2点リード／3点以上リードの7群。3状態（リード/同点/ビハインド）も別に合算。
- 各群の試合数・全対象に占める割合・最終W/L/T・勝利割合W/G・通常勝率W/(W+L)・以後得失点と実攻撃回数を保存する。引分を敗戦と同一視せず、全勝敗分割を保持する。

## 命題候補と反例

年別に同年同リーグ他5の合算と比較する。主比較の会場はall、ホーム/ビジター別も併記。期間合算は各球団試合の合算であり、全球団で同じ試合が対戦相手の観測として重複することに留意する。

- S1「中日はビハインドで7回を終える割合が高い」：差>0を記述的支持、差<=0を反例。
- S2「中日はリードで7回を終える割合が低い」：差<0を支持、差>=0を反例。
- S3「リードで7回を終えた中日は最終勝利割合W/Gが低い」：差<0を支持、差>=0を反例。リード幅の分布が異なるので、この比較だけで守備・救援能力差とはしない。7分類を並べて幅による違いを確認する。
- 3命題を無理に一本化せず、年別判例を全て保存。2019年に合うまで閾値や分類を変更しない。各指標の比較方向は有意差や因果関係の判定ではない。
- 他11球団にも同じ比較を実施し、中日固有かの断定を避ける。6回・会場別・2020込みは固定した感度である。
