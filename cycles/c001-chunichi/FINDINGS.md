# サイクル1 の到達点：中日ドラゴンズはなぜ B クラスが続いたのか

記録: 2026-10-04。R1〜R17 と命題 P1〜P80 までの時点のまとめ。
数値はすべて各研究記録（`research/R*.md`）と自動生成の出力（`outputs/`）から写した。全命題の最新の判定は [`outputs/index.md`](outputs/index.md)（自動生成）にある。

## 1. 問いと、答えの形

- **問い**: 中日ドラゴンズは、なぜ 2013〜2026年に B クラス（4〜6位）が続いたのか。1〜3位になれなかったのはなぜか
- **答えの形（ユーザーが決めた完了の形）**: 理由を、「または」「かつ」を含んでよい条件の式で書き、プログラムで再現できること。人が一言で言える形でなくてよい。正解は1つではなく、言いやすい式と、言いにくくても確実に選ぶ式が並んでいてよい
- **2020年**（120試合、セは CS なし、中日は3位）は例外として統計から除き、判例の一覧には残す
- 範囲: 2012〜2025年の12球団（イニング単位は 2013〜2025年）。2026年はまだ取り込んでいない

## 2. いまの答え（式）

どれも、作るきっかけになったデータと同じデータで選んだ・見つけたもので、**2026年以降のデータで判定し直すのが確かめになる**。

### 式1: B クラスになる条件（R11、P52）

```text
[sim_p_upper < 0.4] または [alloc_z_strat < −1]  ⇒  B クラス
```

- `sim_p_upper`: その年の得点・失点の分布だけからシーズンを作り直したとき（R10）、A クラスに入る確率
- `alloc_z_strat`: 得点と失点がどの試合で組み合わさったかの、ランダムな基準からのずれ（R1。−1 未満は基準より1標準偏差を超えて不利）
- 全球団156単位で、元の命題・対偶・逆・裏の4つすべて支持（exit 1）。B クラスの 94% がこのどちらかに当たる（Matthews 相関 0.809）
- 中日の B クラス12年のうち **11年**を説明する（10年は分布の見込みが低い側、2019年は組み合わせ方が不利な側）。説明できないのは **2014年**
- 17個の候補条件から総当たりで探した式（`rule_candidates.toml`、`outputs/rules.jsonl`）

### 式2: 低いまま続くと B クラス（R14、P62・P63）

```text
得点した回の大きさがリーグ下位2位以内の年が2年以上続いている  ⇒  B クラス
```

- 16単位中16（中日 9、他球団 7）。元の命題・対偶は異議なし（exit 0）。中日以外の7単位でも例外がない（P63、単位が少なく判断保留）
- 逆（B クラスなら続けて低い）は 0.22 で弱い。B クラスになるための**十分条件だが必要条件ではない**
- 「その年と前年がどちらも下位2位以内」は、中日が10回（セ・リーグ、2020年を含む）、他球団は最大2回。他球団はどれも2年で途切れ、**3年以上続いたのは中日だけ**

### 式3: 境目の2年は別の道筋（R17）

| 年 | 道筋 | 式 | その年を除いた確かめ |
|---|---|---|---|
| 2014年 | 分布の上では届くのに4位 | 4位 かつ `sim_p_upper ≥ 0.5` ⇒ 強い相手との試合で点の差どおりに勝てていない（`opp_conv_top < 0`、P78） | **7単位中6**（一般の形） |
| 2019年 | 得失点差プラスなのに B | 強い相手から点が取れない（P76）、強い相手との試合全体の点が少ない（P80） | 11単位中 4・5（**中日だけの形**） |

同じ B クラスでも、2014年は「点の差を勝ちに変えられなかった」、2019年は「強い相手から点そのものが取れなかった」。

### 式4: 鏡の形（R17、P79）

```text
強い相手に対して得点が（同じ年・同じリーグの平均と比べて）見込みより少ない  ⇒  失点も見込みより少ない
```

- 4つの形のうち3つで支持（lift 1.25、p = 0.001）。得点の差と失点の差の相関は、強い相手 −0.29、中位 −0.18、弱い相手 −0.10
- 強い相手との試合では、「どちらが上回ったか」より「試合全体が点の入りやすい展開だったか」のほうが大きく動く。得点と失点が一緒に動く

## 3. 説明の層（なぜ B クラスか）

上の層ほど結果（順位）に近く、下の層ほど原因に近い。

| 層 | 分かったこと | 研究 |
|---|---|---|
| 順位 | 中日の A クラスは1回（2012年）、分布からの期待値は 3.39回。実際の回数以下になる確率は 0.052（2013〜2025年に限ると 0.041、結果を見た後の計算）。力が同じなら 0.00024 なので、**珍しさのほとんどはその年の得点・失点の分布で説明できる** | R10 |
| 得点と失点 | 失点がリーグ2位以内でも、低得点のチームの A クラスは16単位中6だけ。分かれ目は得失点差。中日は失点を抑えた年（2014・2019・2021・2022）も届かなかった | R2 |
| 得点の不足の形 | 点が入る回の少なさ（頻度）は他の低得点のチームと同じ（−0.103 対 −0.096）。**点が入った回の小ささ（大きさ）が中日に固有**（−0.077 対 −0.027） | R4 |
| 得点した回 | 3点以上の回が少ない年が **11年中11年**。ホームでもビジターでも同じ（どちらも 11年中10年） | R5 |
| 打撃 | 打率は人並み（−.005、他の低得点のチームは −.009）。**四死球と長打がそれぞれ別々に少ない**（四死球／打席 −.011、ISO −.022）。出塁が安打に偏る（四死球による出塁の割合 −2.5ポイント） | R6〜R9 |
| 持続 | 続いているのは年ごとの上下ではなく**水準**。得点した回の大きさの平均は −0.076（次に低い球団は −0.013）、年ごとの相関は 0.25 で他球団並み。「毎年の天気」ではなく「土地の標高」 | R14 |
| 境目の年 | 2014年は強い相手との試合で点の差を勝ちに変えられず（変換 −2.6勝）、2019年は強い相手から点が取れなかった（同じ年・同じリーグの平均より −57点、失点は +13点） | R12〜R17 |

## 4. 弱めた・取り下げた見方（異議の記録）

| 見方 | どうなったか | 研究 |
|---|---|---|
| 得点・失点の組み合わせ方（接戦の勝ち負け）が低迷を説明する | 期間合計 −15.6（z = −0.77）で偶然の範囲。翌年への持続もない（相関 0.08） | R1 |
| 失点でも補えなかった | 失点を抑えた年もあった。得点の不足がそれを上回った | R2 |
| 抑え込まれる試合（0〜2点）が多いのが中心 | 得点の量で見ると、高い得点帯の不足のほうが大きい。帯の幅をそろえても同じ（−0.121 対 −0.081） | R3・R7 |
| 点が入る回が少ないだけ | 頻度は他の低得点のチームと同じで、違うのは大きさ | R4 |
| 本拠地だけの問題 | ホームでもビジターでも同じ形 | R5 |
| 四死球の不足が主 | 四死球と長打の結びつきは同程度（0.43 と 0.44）。出塁率の結びつきが強かったのは打率を含むから（R6 の読みを訂正） | R7 |
| 勝負を避けられない（怖がられていない） | 故意四球の割合はむしろ高め。使わない | R8 |
| 低得点のチームの順位を分けるのは打撃の形 | 分けていたのは失点の順位（A 2.25 対 B 3.89） | R8・R9 |
| 「組み合わせ方の不運」 | 言い方を取り下げた。基準からのずれは「基準より不利」と書き、まだ測れていない何かの痕跡として扱う | R11 |
| 3位を争う相手に勝っておくことが境目を分ける | 測り方を直しても1組ずつでは分けない（lift 1.08〜1.15）。ただし平均では、4位は強い相手に勝ち（+2.10）、中位・弱い相手に取りこぼす（−1.70、−1.10） | R13・R15 |
| 中日は強い相手に毎年打てない・打たれる | 毎年ではない（13年中6年・4年）。掛け算の見込みの式に偏りがあった（強い相手に +7.3点）ので、同じ年・同じリーグの平均を引いて読み直した | R16・R17 |
| 中日だけが年ごとに強く続く | 年ごとの相関は他球団並み（0.25）。続いているのは水準 | R14 |
