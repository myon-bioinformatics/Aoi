# R1: 得点・失点の配分（研究計画）

記録: 2026-10-03。計算を始める前に書いた。

## 位置づけ

**探索的な研究であり、確認試験ではない。** 外部レポート（`../references/`）の集計をすでに見ている。
そのため、ここで得た結果は「次に確かめる仮説」を作るためのもので、仮説を確定させるものではない。
確認には、計画を書いた後に初めて見るデータ（例: 2026年の最終成績、2027年以降）を使う。

## 問い

同じ総得点・総失点でも、それが**どの試合で組み合わさったか**によって、勝ち越し数はどれだけ変わるか。
「接戦に強い」と呼ぶ前に、得点・失点の分布を保った比較を置く。

あわせて、

1. その配分の特徴は、翌年にも続くか
2. ホームとビジターで違うか

## 方法

### 配分効果

チーム×シーズンごとに、1試合ごとの得点の並び（RF）と失点の並び（RA）を、それぞれそのまま保つ。
組み合わせだけを入れ替えたときの勝ち越し数（勝 − 敗）を基準にする。

```text
c(i, j) = 符号(RF_i − RA_j)        （勝ち +1、負け −1、引き分け 0）
基準    = 組み合わせ π を一様にランダムに選んだときの Σ c(i, π(i)) の分布
期待値  = (1/n) Σ_i Σ_j c(i, j)
分散    = 1/(n−1) Σ_i Σ_j d(i, j)²    d(i,j) = c(i,j) − 行の平均 − 列の平均 + 全体の平均
配分効果 alloc_net = 実際の（勝 − 敗）− 期待値
標準化   alloc_z   = alloc_net / √分散
```

期待値と分散は、組み合わせの入れ替えに関する厳密な公式（Hoeffding, 1951）で求める。乱数を使わないので、同じデータからは常に同じ値になる。
公式の実装は、小さな例で全通りの入れ替えを数えた結果と照合して確かめる。

ピタゴラス期待勝率との違い: ピタゴラスは総得点・総失点だけから勝率を推定する（得点の分布の形は使わない）。
配分効果は、そのチームのその年の得点・失点の分布の形をそのまま使う。

### 層別（ホーム／ビジター）

ホームの試合どうし、ビジターの試合どうしの中だけで入れ替えた基準も作る（`alloc_*_home`、`alloc_*_away`、合計は `alloc_*_strat`）。
これは球場の補正係数ではない。同じ環境の試合の中でだけ比べる、という比較条件の変更である。

### 続くか

隣り合うシーズン（同じチームの t 年と t+1 年）の alloc_z の相関を、全チームについて求める。
同じ計算を、ピタゴラスからのずれ（resid_fixed）と勝率（wpct）にも行い、並べて読む。

### 層別（対戦相手 × ホーム／ビジター）

同じ相手・同じ主催区分の試合どうしの中だけで入れ替えた基準も作る（`alloc_*_opp`）。PR #3 の R001 と同じ比べ方で、相手の強さの違いが組み合わせに見えている分を除く。

### 外部の独立研究との照合（2026-10-03 追記）

PR #3（GPT の研究 R001）が、同じ問いを実データ（2013〜2025年）で先に計算している。
得点を固定して失点だけを 4,000回並べ替え、勝相当 WE = W + 0.5·D の平均との差を見る方法で、こちらとは計算の仕方が違う。

- 並べ替えでは試合数 n が変わらないので、勝 − 敗 = 2·WE − n。よって**勝 − 敗の超過 = 2 × WE の超過**（引き分けを含めて成り立つ。全通りを数えるテストで確認した）
- したがって、R001 の値はこちらの `alloc_net_strat`（ホーム／ビジター内）と `alloc_net_opp`（相手も保つ）の値の半分になるはず
- この照合を `claims.toml` の C20〜C23 に登録した。合わなければ、どちらかの観測（試合の集合）か計算に違いがある

R001 の結果（中日の超過は平均 −0.73 WE／年、翌年への相関はセでほぼ 0）は、下の「見直す条件」の1つ目と2つ目に当たる。
実データで再現したら、「配分が低迷を説明する」「配分はチームの特徴として続く」という見方はどちらも弱める。

## 見直す条件（反証）

- 中日の alloc_net の期間合計が 0 付近（偶然の範囲）なら、「配分が低迷を説明する」という見方を弱める
- alloc_z の隣り合うシーズンの相関がピタゴラスのずれと同程度に小さいなら、「配分はチームの特徴として続く」という見方を弱める
- ホームとビジターで alloc_z の符号がそろわないことが多いなら、「配分の特徴はチーム全体のもの」という見方を弱める

## 限界

- 使うのは最終スコアだけ。どのイニングで点が入ったか、誰が投げたかは分からない（イニング単位の仮説 H5〜H7 は保留のまま）
- 実際の組み合わせはランダムではない。同じ試合の得点と失点は、同じ相手・同じ球場・同じ日の条件を共有している
- **打ち切り**: ホームチームは9回表終了時点で勝っていれば裏の攻撃をしない。サヨナラ勝ちでは決勝点の時点で試合が終わる。そのため勝ち試合のホームの得点は低めに打ち切られ、基準にも偏りが入る。ホーム／ビジターの層別は、この偏りが結果を左右していないかを見る目安にもなる
- 引き分け（12回打ち切り）は c = 0 として数える
- 配分効果は「どうずれたか」の記述であって、「なぜか」（継投、起用、運）の説明ではない
