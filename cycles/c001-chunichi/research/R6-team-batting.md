# R6: 得点した回が小さいのは、長打の不足か、出塁の不足か（研究計画）

記録: 2026-10-04。計算を始める前に書いた。チーム打撃成績のページはまだ1件も取得していない（形の確認で3ページの見出しと1行だけを見た）。

## 位置づけ

**探索的な研究。** R4・R5 の結果（中日に固有なのは得点した回の小ささ。3点以上の回が毎年少ない）を見たうえで、打撃のどの面と結びつくかを見る。
記憶では、中日の本拠地は本塁打が出にくい球場と言われることが多い。**球場の係数は使わない**（方針）。ここではチームの打撃成績を、同じ年・同じリーグの他球団と比べるだけにする。

## データ

npb.jp のチーム打撃成績（`blueprobe/docs/npb_team_batting.md`）。2012〜2025年、28ページ。
照合: 試合数・得点がカレンダー由来の値と一致し、打率・長打率・出塁率を計算し直すとページの値と一致すること。合わなければ測る前に止まる。

## 方法

率はすべて打数・打席などから計算し直す。同じ年・同じリーグの他球団の平均との差（`bat_d_*`）で比べる。

| 列 | 意味 |
|---|---|
| `bat_iso` | 長打率 − 打率（長打の力。単打を除いた塁打／打数） |
| `bat_obp` | 出塁率 |
| `bat_hr_pa` / `bat_bb_pa` / `bat_so_pa` | 本塁打・四死球・三振の打席あたりの割合 |
| `bat_xbh_h` | 安打のうち長打の割合 |

| 命題 | 内容 | 強さ |
|---|---|---|
| P31 | 低得点（得点5位以下）の年の中日は、ISO が他球団より低い | 概ね（0.75） |
| P32 | 低得点の年の中日は、出塁率が他球団より低い | 概ね（0.75） |
| P33 | 全球団で、ISO が他球団より低ければ、得点した回のうち3点以上の回の割合も少ない | 概ね（0.75） |
| P34 | 全球団で、出塁率が他球団より低ければ、得点する回の頻度も低い | 概ね（0.75） |

P31・P32 は 2012〜2025年、P33・P34 はイニング集計のある 2013〜2025年。`analysis.toml` の除外（2020年）を適用。
P33 と P34 の逆・裏もあわせて読む（3点以上の回が少なければ ISO が低いか、など）。

## 見直す条件（反証）

- P31 が成り立たず P32 が成り立つなら、「中日は長打が足りない」という見方を弱め、出塁（得点の頻度の側）に戻る
- P33 が成り立たない（ISO が低いのに3点以上の回が他球団以上のチーム・シーズンが4分の1を超える）なら、ISO と大量点の回を結ぶ見方そのものを弱める。中日の R5 の結果を長打で説明することもできなくなる
- P34 が成り立たないなら、出塁と得点の頻度を結ぶ見方を弱める

## 限界

- 打撃成績はシーズン全体の値で、イニングや走者の状況とは結びつかない。「長打が少ないから3点以上の回が少ない」は、チーム・シーズン単位の対応であって、個々の回の因果ではない
- ISO と出塁率は互いに相関する（長打の多いチームは四球も多い傾向がある）。P33・P34 は片方ずつ見るだけで、どちらがより効くかは分けない
- 球場・相手・DH の違いは、同じ年・同じリーグの他球団と比べるだけで補正しない。セとパを混ぜて比べない

## 取得で起きたこと（2026-10-04）

- `--strict` の構造確認が2回、測る前に止めた。2012〜2024年の実ページは、見出しの語の中（「打 率」）と2文字のチーム名（「中 日」）に空白が入っていた。WebFetch で見た形には出ていなかった。どちらも観測した形だけを読むように直した（`blueprobe/docs/npb_team_batting.md`）
- **負荷**: 止まった実行では Actions のキャッシュが保存されず、次の実行で同じ28ページを取り直した。チーム打撃成績のページへのリクエストは合計 112回（28 × 4回の実行）になった。止まっても保存するように直したので、以後は 0回
- 照合: 168球団年すべてで、試合数・得点がカレンダー由来の値と一致し、打率・長打率・出塁率を計算し直すとページの値と一致した

読めること（記述）:

- 中日の低得点の年は、**長打（ISO）も出塁率も毎年他球団より低い**。打率は他の低得点のチームより低くない（−.005 対 −.009）
- 中日に目立つのは、**四死球の少なさ**（他の低得点のチームの約2倍）と**長打の少なさ**（同じく約1.6倍）。安打の数ではなく、安打以外の出塁と、安打の質（長打）の側に不足がある
- 安打のうち長打の割合（xbh_h）は、13年中12年で他球団より低い（2025年 +0.001 だけが例外。計算後に見た値で、命題にはしていない）

## 自分への異議（計算後）

計画では「長打 ↔ 得点した回の大きさ」「出塁 ↔ 得点する回の頻度」と対応させていた。
しかし相関を見ると、**得点した回の大きさは、ISO（0.44）より出塁率（0.63）とのほうが強く対応している**。P33 も「概ね」には届かなかった。
得点した回の大きさは、長打だけでなく、走者をためること（四球・死球を含む出塁）にも左右される、という当たり前の見方に戻る。

したがって R5 の「3点以上の回が少ない」を、長打の不足だけで説明するのは強すぎる。中日については、
**長打の不足と四死球の不足の両方**が、得点した回を小さくしている候補として残る。どちらがどれだけかは、チーム・シーズン単位のこのデータでは分けられない（ISO と出塁率の相関は 0.48）。

## R1〜R6 のつながり（2026-10-04 時点）

中日の 2013〜2025年の低得点は、

1. 得点・失点の組み合わせ方（R1）や、失点の多さ（R2）では説明できず、得点の不足の大きさそのものが中心にある
2. その不足は、点が入る回の少なさ（低得点のチームに共通）に加えて、**点が入った回の小ささ**（中日に固有）から来ている（R4・R5）
3. 打撃成績では、**打率は他の低得点のチームと同じくらいで、四死球と長打が少ない**（R6）

「なぜ四死球と長打が少なかったのか」（選手の構成・起用・本拠地）は、チームの年間成績からは分けられない。ここから先は、選手単位のデータが必要になる。
