# ε の汎用性の確認（第 5 回）: 倍率を帯 1×10^-7〜1×10^-4 から選んだ結果（探索）

事前登録は [../README.md](../README.md) の「倍率を帯から選ぶ確認（第 5 回）: 事前登録」（コミット d8e4466。ソースは `eps_generality.py` の `--scale-range`、変更なし）。範囲は inside 1×10^-7〜1×10^-4、個数 10、種 `20261027`、走らせる前に書いた予想 (a)〜(d) のとおりで、**結果を見て変えていません。** 実行はコミット d8e4466 の作業ツリー（変更なし）で、3 つの入力は第 1〜3 回と同じ（主食価格の月次 `staple_survey_vertical.csv`、物理量の月次・日次。物理量の SHA-256 は [../results-physical/physical_manifest.json](../results-physical/physical_manifest.json) と一致）。倍率の値と帯は暫定で、結論には使いません。

`staple/`・`monthly/`・`daily/` に `eps_generality.{json,md}` があります（単位ごとの行は置いていません。種と範囲が結果に書いてあるので、下の「再現」で作り直せます）。倍率は報告だけで基準はありません。

## 要点

- **登録した予想 (a)〜(d) は、3 入力ともすべて当たりました。** (a) 倍率が小さいほど、式が変わった単位は増える側にしか動かない（3 入力とも、10 個の倍率を大きい順に並べて、数が減ることはありません）。(b) 倍率が事後の格子の隣り合う 2 点の間にあるとき、数はその 2 点の値の間（30 個すべて）。(c) 物理量の月次は 1×10^-5 以上の 3 個で 0。(d) 式が変わった単位が 0 の倍率では `boundary_flag_changed` も 0
- **帯の上の端は動きません。** 9.57×10^-5 と 5.98×10^-5 では、式が変わった単位は 3 入力とも 0。3.16×10^-5 では主食価格と物理量の日次が 1 単位ずつ（月次は 0）
- **帯の中ほどは、倍率とともに単調に増えます。** 8.91×10^-6 で 20 / 2 / 10 単位（主食価格 / 物理量の月次 / 日次）、1.92×10^-6 で 489 / 48 / 110 単位。**半分を超えるのは、3 入力とも 1.92×10^-6 と 9.50×10^-7 の間**です（主食価格 2192 単位の半分は 1096 で、1.92×10^-6 は 489、9.50×10^-7 は 1122。月次 221 の半分は 110.5 で 48 → 122。日次 478 の半分は 239 で 110 → 281）。結果を見たあとの読みで、基準ではありません
- **帯の下の端（1.03×10^-7）では、倍率 1 で境界だった単位が、3 入力ともすべて境界でなくなります**（778 / 85 / 180 単位）。式が変わった単位は 2099 / 207 / 470 で、格子の 1×10^-7 の値（2103 / 207 / 470）とほぼ同じです
- **予想を置かなかった列**: 係数のずれの最大（境界のままの単位）は、主食価格の 1.92×10^-6〜7.66×10^-7 の 4 個で 1.27〜1.31（1.03×10^-7 は境界の単位が 0 で値なし。ほかの倍率では 10^-15〜10^-14 台）。物理量の月次・日次では、どの倍率でも 10^-16〜10^-15 台です。主食価格のこの大きなずれの原因（周期の切り替わりによる係数の飛びと思われます）は、見ていません
- 基準（C1〜C5）は決め打ちの ε だけで評価され、今回は第 1 回から変わりません。対照 C4 と同じ入力の繰り返しの一致は、3 入力とも通りました。基準の満たさなかった件は主食価格の 12 か月の窓の C2（決め打ちの ε=1e-3、第 1 回から同じ）の 1 件だけです

## 読み取れること（この 3 入力・24 点の窓で）

- 事後の格子（10 のべき）で見えた「変わり始める帯」が、格子の間の倍率でも同じ向きに続いています。変わる単位の数は 1×10^-5 より上でほぼ 0、1×10^-6 の前後で半分を超え、1×10^-7 で境界の単位がすべて入れ替わります。向きは、絶対値の許容 `EPS_WAVE_TIE`（1e-12）が誤差の2乗和の尺度（倍率の2乗）に対して相対的に大きくなる、という第 2・3 回の事後の読みと合っています。**今回の 10 個の倍率について、許容に倍率の2乗をかけた場合は走らせていません**（確かめたのは格子の倍率まで）
- 倍率の選び方（幾何分布で指数を選ぶ規則）で、この帯の 10 個が 3 / 3 / 4 個（1e-5 以上 / 1e-6 以上 1e-5 未満 / 1e-6 未満）に分かれたことが、帯の中ほどの様子を見る助けになっています。別の種で同じ数に分かれるとは限りません

## 限界

- 1 つの種の 10 個。単位数は主食価格 2192、物理量の月次 221、日次 478（24 点の窓）で、式が変わった単位が 1〜2 の倍率（3.16×10^-5、8.91×10^-6 の月次）は、数が小さいので「判断できない」（予想の範囲に入っただけ）
- 24 点の窓だけ。12 点・48 点の窓は倍率の表に入れていない（第 3 回と同じ）
- 窓は独立ではない（互いに重ならない窓だが、同じ系列から取る）。物理量は大気・気候の測定に偏る（第 2 回の限界のまま）
- 基準はなく、倍率の値や許容 `EPS_WAVE_TIE` をどうするかは決めていない。`sakanalytics` は変更していない（PR #24 は触らない）
