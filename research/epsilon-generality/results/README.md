# ε の汎用性の確認: 結果（探索）

[README.md](../README.md) に事前に書いた基準を、主食価格の月次の窓と合成の系列に当てた結果です。スクリプトは `eps_generality.py`・`posthoc_boundary_forms.py`（コミット 9841b28 の版）。**基準は結果を見て変えていません。** ε の値は暫定で、結論には使いません。

## 要点

- 登録した基準は、判定できた 29 件のうち **28 件を満たし、1 件を満たさなかった**。対照（C4）は通った。判定不能はなし
- 満たさなかった 1 件は、C2（窓 12 か月、ε=1e-3 の係数のずれ）。4,661 窓のうち 1 窓（境界の単位 1,817 のうち 1）で、**ε を入れたことで壊れたのではなく、ε=1e-3 のときだけ、誤差がほぼ同じ 2 つの周期（1 と 2）の選ばれ方が入れ替わった**ため（下の「事後の確認」）。12 か月ではもう 1 窓（境界でない単位）も、ε=1e-3 のときだけ選ばれる式が変わった。ε=1e-6 と 1e-9 では、どの窓の長さでも起きていない
- 野球と違った点: 「減衰 0」が選ばれる単位（境界の単位）の割合が **約 36〜39%**（野球は 24 / 168 = 約 14%）。ε が効く場面は、価格データのほうがずっと多い。出どころごとに見ても同じ（下）
- 野球と近かった点: 境界の単位の周期の中身（周期 2、つまり「半周期の波 = 窓の中で落ち着かない一方向の動き」が約 7 割）、係数の範囲（ε=1e-6 で 0.03〜2.4。野球は 0.077〜1.76）、ε が小さい範囲で結果が ε によらないこと

「確かめられた」とは書きません。見たのは、主食価格の月次（5 つの出どころ。24 か月の窓があるのは 4 つ）と、答えの分かる合成の系列で、基準に反する材料があったか、です。

## 事後の確認（登録した基準の外）

結果を見たあとに、ε=1e-3 で式が変わった 2 つの窓を調べました（[posthoc_boundary_forms.md](posthoc_boundary_forms.md)。誤差の2乗和は、その式だけで当てはめた値）。どちらも、ε=1e-6 と 1e-9 では起きていません。

**1. C2 を満たさなかった境界の単位**。WFP の年次ファイルのモルドバの高品質小麦粉の価格（MDL per KG）、2024-01 から 12 か月。ε=1e-6 と 1e-9 では周期 1 の ε の波が、ε=1e-3 では周期 2 の ε の波が選ばれています。

| ε | 周期 1 の式 | 周期 2 の式 |
|---|---|---|
| 0（今のコード） | 4.8284 | 4.8336 |
| 1e-3 | 4.8365 | 4.8347 |
| 1e-6 | 4.8284 | 4.8336 |

もともと周期 1 のほうが 0.1% だけ良い（ほぼ同点）。ε=1e-3 だと周期 1 の式の誤差が 0.008 増えて、周期 2 の式に追い越されます。**この窓では、ε が大きすぎてほぼ同点の式の順が入れ替わった**のであって、ε の波の計算が壊れたわけではありません。

**2. 境界でない単位**。FPMA のアゼルバイジャンのパン用高品質小麦粉の価格（AZN per Kg）、2016-02 から 12 か月。今のコードは 減衰 0.5・周期 2 を選び、ε=1e-3 では 減衰 0.001・周期 2 の ε の波が選ばれます。

| 式（周期 2） | 誤差の2乗和 |
|---|---|
| 減衰 0.5（今のコードで選ばれた式） | 2.41937 |
| 減衰 0（減衰しない） | 2.41944 |
| ε=1e-3 | 2.41932 |
| ε=1e-6 | 2.41944 |

ε=1e-3 の波は、減衰 0 より誤差が下がり（2.41944 → 2.41932）、減衰 0.5 の式も追い越します（差は 4×10^-5）。ε=1e-6 は減衰 0 とほぼ同じで、0.5 の式に勝てません。減衰 0 のあたりで誤差が下がっていくので、この窓の最適な減衰は 0 と 0.5 の間にあると読めます。**格子（0、0.5、1、…）が粗く、ε=1e-3 はその間に入る候補として働いた**、ということです。

野球でも、ε=1e-3 のときだけ選ばれる式が変わった単位が 1 つありました（2024年のソフトバンク）。**同じ仕組みかどうかは、この単位の誤差を並べていないので、確かめていません。** 野球の ε の格子の感度では、この単位は 0.03・0.001・1e-12 で乗り換えていて（[wave_eps_sensitivity.md](../../../cycles/c001-chunichi/exploratory/wave_eps_2026_results/wave_eps_sensitivity.md)）、上の 2 つのような「ε が大きいときだけ」という形とは限りません。

境界の単位の周期の中身（窓の長さごと）:

| 周期 | 12 か月 | 24 か月 | 48 か月 | 野球（24 単位） |
|---|---|---|---|---|
| 2（半周期） | 70.5% | 72.0% | 70.4% | 70.8%（17） |
| 1 | 15.3% | 10.9% | 15.2% | 16.7%（4） |
| 0.75 | 9.5% | 8.6% | 7.5% | 12.5%（3） |
| 0.5 以下 | 4.7% | 8.5% | 6.9% | 0 |

出どころごとの境界の割合（24 か月）: BLS 25 / 58（0.43）、FPMA 436 / 1,263（0.35）、WFP 260 / 716（0.36）、WFP の年次 57 / 155（0.37）。e-Stat は 24 か月続く区間がなく、12 か月だけ入る。

## 野球に寄っていた点・領域によらない点

領域によらなかったもの（上の範囲では）:

- 減衰 0 を ε に差し替える方法そのもの。差し替えた先が選ばれ、収束先と落ち着く位置が有限で出る（C1）。落ち着く位置を「係数 × 10^n」と書いたときの係数は、ε が小さい範囲（1e-6 以下）で ε によらない（C2）
- 境界でない単位の結果を動かさない（C3、ε=1e-6 以下で 0）
- 合成の答え合わせ（C5）

野球に寄っていたもの（コードを読んで挙げた一覧は [README.md](../README.md#野球に結びついている部分コードを読んで挙げたものこのハーネスでの扱い)）:

- **「ε が効く単位の割合」**: 野球の約 14% は、価格データでは約 36% でした。野球の数を ε の影響の大きさの目安にすると、少なく見積もる
- `WAVE_SETTLE = 0.5`（半順位）。ここでは値の幅を 5 にそろえ、τ を 0.25 / 0.5 / 1.0 と動かした。式の選び方は τ によらず（3 通りとも同じ）、係数は ln(振幅/τ) なので τ で平行にずれるだけ。「始まりの時点で決まっていた」単位は、τ=0.5 で 778 のうち 1、τ=1.0 で 50（6.4%）。τ は領域ごとに決める値で、野球の半順位をそのまま持ち込めない
- ε の意味は x の単位で決まる（位置 ≈ 係数 / ε）。ここでは窓の長さを 1 にして ε を置いた。別の長さの単位で使うときは、どの長さに対する ε かを先に決める必要がある
- `sakanalytics` の `EPS_WAVE_TIE = 1e-12` などは絶対値で、値の幅 5 前後の尺度を前提にしている。ここでは値の幅を 5 にそろえて使った

## 限界

- 実データは**主食価格だけ**。野球から離れたが、一つの種類（価格の月次）で、人口・指標などは入っていない（物理量は [第 2 回](../results-physical/README.md)。ε と倍率を A×10^-N の乱数で選んだ値での確認は [第 3 回](../results-random/README.md)）
- 窓の長さ・τ・合成の系列は任意の選び方。基準値は野球の値を目安にした。同じ系列の窓は独立ではないので、窓の数は独立な標本の数ではない
- 境界の割合が高いことの理由（価格の動きが一方向に続きやすい、など）は調べていない。周期 2 が 7 割という中身が野球と近い、までしか言えない
- 事後の確認は基準ではない。ε=1e-3 で式が変わった 2 窓の仕組み（ほぼ同点の周期の入れ替わり、粗い格子の間に入る候補）は、その 2 窓での読みで、一般化していない。野球の 2024年ソフトバンクが同じかは未確認
