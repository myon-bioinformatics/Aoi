# R25: 線の始まりを変えても、R22・R23 の読みは保たれるか（研究計画）

記録: 2026-10-04。計算を始める前に書いた。R22・R23 の結果（線の始まり = 全球団が10試合）は見ている。

## 位置づけ

R23 で、線の始まり（全球団が何試合を終えた段階から線を引くか）を設定で変えられるようにした（ユーザーの指摘）。今回は 10試合で読んだ。始まりを変えても読みが同じかを、**5・20・30試合**で確かめる（[analysis.toml](../analysis.toml) の `[trajectory] sensitivity`）。

## 方法

始まり以外はすべて R22・R23 と同じ（3次式、減衰する波の格子、力が一定のシーズン200回）。試合数ごと・群（中日の B クラス・他の B クラス・A クラス）ごとに、`outputs/trajectory_sensitivity.jsonl` に並べる:
順位が決まった位置の中央値、決まらなかった数、力が一定のときより早く決まった割合、減衰する波の割合、収束する先が最終順位から1未満の割合、順位・貯金の線の山の数と見込み。

## 読み方（先に決める）

次の4つが、5・10・20・30試合のすべてで成り立てば「読みは保たれる」。成り立たない試合数があれば、その読みは線の始まりに左右されると書く。

1. 中日の B クラスの年の、順位が決まった位置の中央値が、他の B クラスより早い（R23 の「中日は早く決まる」）
2. 力が一定のときより早く決まった割合が、中日の B クラスのほうが他の B クラスより高い（R23 では差 0.29）
3. 収束した単位のうち、収束する先が最終順位から1未満の割合が、どの群でも 0.85 以上（R23 の「最終順位へ収束する」）
4. 中日の順位・貯金の線の山の数が、力が一定のときの見込みの範囲（P(見込み以上) ≥ 0.05。R22 の「中日の山はゆらぎの範囲」）

## 限界

- 始まりを遅くするほど線は短くなり、早い時期の動きは見えなくなる（30試合はおよそ5月上旬）
- 4つの読みを同時に見るので、どれか1つが偶然外れることはありうる。外れた読みは、どの試合数で・どれだけ外れたかを書く
