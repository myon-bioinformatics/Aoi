# R13: 3位を争う相手に勝てていたか（研究計画）

記録: 2026-10-04。計算を始める前に書いた。`vs_battle_wpct`・`focus_gap`・`pair34_*_diff` は実データでまだ計算していない。

## 位置づけ

R12 の計算後に、3位と4位の差が「上位の相手との勝率」ではなく「下位の相手との勝率」に出ていることが見えた（.556 対 .523）。
ユーザーの見方: **3位を狙うなら、1位・2位には最悪負けてもいいが、3位を争う相手（自分の1つ上・1つ下、3〜5位）には勝っておく必要がある。** そのための力の配分（どの相手に誰をぶつけるか）は、球団の判断が表に出る場所でもある。
これを指標にして、境目（3位と4位）を分けるか、中日に当てはまるかを見る。

P57 は R12 の結果を見た後に作った命題（確かめではない）。P58〜P61 は、新しい指標でまだ値を見ていない。

## 方法

同じリーグの相手だけ。最終順位で相手を分ける（6球団なら）。

| 指標 | 相手 |
|---|---|
| `vs_top_wpct` | 1・2位 |
| `vs_battle_wpct` | 3〜5位（自分を除く） |
| `focus_gap` | `vs_battle_wpct − vs_top_wpct`。争う相手に重点を置けていたか |
| `vs_lower_wpct_d` | 下位半分の相手との勝率の、他球団平均との差 |
| `pair34_*_diff` | 3位と4位の間で、相手チームとの差 |

| 命題 | 範囲 | もし | ならば | 強さ |
|---|---|---|---|---|
| P57 | 3位と4位 | 下位の相手との勝率が相手チームより高い | 3位 | 半分より多く |
| P58 | 3位と4位 | 3位を争う相手との勝率が相手チームより高い | 3位 | 半分より多く |
| P59 | 3位と4位 | 争う相手への重点（focus_gap）が相手チームより大きい | 3位 | 半分より多く |
| P60 | 全球団 | 組み合わせ方が基準より不利（alloc_z_strat < −1） | 下位の相手との勝率が他球団平均より低い | 概ね |
| P61 | 中日（全年） | — | 争う相手との勝率が上の相手との勝率より低い（focus_gap < 0） | 概ね |

R12 の基準（P56: 分布の見込み ⇒ 3位、lift 1.43）と、P57〜P59 の lift を並べる。
P60 は「下位からの取りこぼし」が R1 の「組み合わせ方が基準より不利」を別の名前で見ているだけかを確かめる（逆・裏も読む）。
あわせて、`vs_lower_wpct_d` と `alloc_z_strat` の相関を記述として出す。

## 見直す条件（反証）

- P58・P59 の lift が 1 に近い（p ≥ 0.05）なら、「争う相手に勝っておく」配分は境目を分けない
- P58・P59 が P56 より大きな lift を持つなら、得点・失点の分布の外にある情報（相手ごとの勝ち方）を足したことになる
- P60 が4つの形すべてで成り立つなら、下位からの取りこぼしと組み合わせ方の不利は、ほぼ同じものを別の名前で見ている。成り立たなければ、別のもの
- P61 が成り立たなければ、「中日は争う相手に負けていた」という見方を弱める

## 限界

- 相手の順位は、その相手との試合の結果も含めて決まる（争う相手に勝てば、その相手の順位は下がる）。逆にたどる面がある
- 6球団では、3〜5位の相手は自分を除いて2チーム、1・2位の相手は2チーム。1チームあたり 25試合前後で、勝率のばらつきは大きい
- 誰を投げさせたかなどの起用は、このデータにない。出てくるのは、相手ごとの勝ち負けという結果だけ
