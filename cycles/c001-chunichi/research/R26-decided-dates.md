# R26: A クラスに入る・入れないが決まった日と、決まるまでのデータで読む線（研究計画）

記録: 2026-10-04。計算を始める前に書いた。`clinch_*`・`decided_x`・`traj_wl_peak_after_clinch` はこの計画のために作った列で、実データではまだ計算していない。R22〜R25 の結果は見ている。

## 位置づけ（ユーザーの見立て）

- 優勝マジックの点灯や、クライマックスシリーズへの出場決定・出場できないことの決定は、新聞なども出せる。1〜3位の顔ぶれが決まれば、中日は自動的に4〜6位のどれかに入る
- それなら、シーズンの終盤のデータを無理に使う必要はない。**1〜3位がいつ決まったか、中日が4〜6位に確定したところまでのデータだけで、計算は足りる**のではないか。その長さは年ごとに違い、それも判断の材料になる

## 方法

### 決まった日（数の上で確かになった日）

各日の終わりに、残り試合（その年の実際の試合数 − 消化した試合数）を**すべて勝つ・すべて負ける**としたときの勝率を、その球団の上限・下限とする。

- **入れない**（B クラスの確定）: 自分の上限より、下限が高い球団が3つ以上
- **入る**（A クラスの確定）: 自分の下限より、上限が低い球団が3つ以上
- **顔ぶれが決まった日**: リーグの全球団について、入る・入れないが決まった日

残り試合どうしの直接対決（片方が勝てば片方が負ける）や、同率のときの決め方は考えない。そのため、公式に決まった日より**遅く出ることはあっても、早く出ることはない**（控えめな日付）。

| 列 | 中身 |
|---|---|
| `clinch_out_x` / `clinch_out_left` | B クラスが確定した日の位置（0〜1）と、その日の残り試合数 |
| `clinch_in_x` / `clinch_in_left` | A クラスが確定した日の位置と残り試合数 |
| `decided_x` | そのリーグで、1〜3位の顔ぶれが決まった日の位置 |
| `traj_wl_peak_after_clinch` / `_base` | A クラスが確定したチームで、貯金の線の山が確定より後にあるか / 力が一定のシーズンで同じことが起きた割合 |

### 決まるまでのデータだけで読む線

R22・R23 の線を、線の終わりを「顔ぶれが決まった日」にして作り直す（[analysis.toml](../analysis.toml) の `[trajectory] ends = ["decided"]`。始まりは10試合のまま）。`outputs/trajectory_sensitivity.jsonl` に、最後の日まで引いた線と並べる。

## 命題

| 命題 | 範囲 | ならば | 強さ |
|---|---|---|---|
| P112 | 中日の B クラスの年 | B クラスが確定した日に、残り試合が10以上あった | 半分より多く |
| P113 | 中日以外の B クラス | 同上 | 半分より多く |

## 読み方（先に決める）

1. **中日の B クラスはいつ決まったか**: 中日の年ごとの確定の日と残り試合を並べる（記述）。P112 と P113 の率の差が 0.2 以上なら、中日の B クラスは他の B クラスより早く決まっている。確定の日の位置を、中日の B クラスと他の B クラスで順位の検定（マン・ホイットニー）でも比べ、σ で書く
2. **A クラスの山は、決まった後か**（R22・R25 で、A クラスの貯金の線の山は力が一定のときより多かった）: `trajectory_expectation.jsonl` の `traj_wl_peak_after_clinch` で、A クラスの「確定後の山」の数を力が一定のときの見込みと比べる。見込みより多く P < 0.05 なら、**決まった後の試合で、チームの戦い方が変わっている**と読む（主力を休ませるなど。起用の記録がないので理由までは言わない）
3. **決まるまでのデータだけで読むと**: 線の終わりを顔ぶれが決まった日にしたとき、
   - A クラスの貯金の山の多さ（見込み超え）が消えるなら、それは**決まった後の試合**から来ていた
   - 中日の読み（R22: 山・谷は力が一定のときの範囲、R23: 最終順位へ収束する）が保たれるなら、**決まるまでのデータで足りる**（ユーザーの見立て）

## 限界

- 決まった日は控えめな日付で、公式の日付（マジック・CS 出場の決定）より遅いことがある。直接対決の残りを考えると早くなる
- 同率（勝率が同じ）で3位と4位が並ぶ年は、数の上では決まらない（空）
- 2020年は他の年と同じく計算するが、統計からは除く

## 読めること

1. **決まるまでのデータで足りる**（ユーザーの見立て）: 線を顔ぶれが決まった日で切っても、R22・R23 の読みはどれも変わらない。決まった後の試合は、読みに効いていない
2. ただし、数の上で（控えめに）数えると決まるのは遅く（シーズンの 96% の位置）、切って省ける計算は平均でシーズンの 4% ほど。公式の日付（直接対決の残りを考えたもの）なら、もう少し早い
3. 中日の B クラスが決まる時期は、他の B クラスと変わらない。中日が早いのは「順位の線が落ち着く」ほうで（R23、4月上旬から見たとき）、数の上の確定ではない
4. A クラスの貯金の山の多さは、決まった後の試合（主力を休ませるなど）からではない。シーズンの途中で力が変わることの別の現れで、理由はこのデータでは分からない
