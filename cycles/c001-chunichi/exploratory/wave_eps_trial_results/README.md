# 波の減衰 0 → ε の試し: 実データでの結果（探索・暫定）

`../wave_eps_trial.py` を実データで走らせた結果です。確定済みの出力（`outputs/season.jsonl` など）は変更していません。**ε の値は暫定の置き場所で、結論には使いません。扱いは今後決めます。** 試合データそのものはコミットしていません（`wave_*` の派生値だけ）。

## 入力の出どころと確かめたこと

- 試合: [PR #127](https://github.com/myon-bioinformatics/Aoi/pull/127) の `observed/games_raw.json`（4,843,030 バイト、SHA-256 `dc75aff5f5f0898716539f2be8f38e0c5aa59f22c994b439c2381fb650c92cdb`、manifest と一致）から、2013〜2025 年の公式戦だけを取り出して `games.jsonl` の形（`key, date, home, away, hs, as`）にしたもの。**ローカルで作っただけで、保存もコミットもしていません。**
- 取り出し方: 終了（final）で両球団のIDがある試合を、日付と URL の順に数え、両球団とも その年の試合数（2013・2014 年は 144、2020 年は 120、ほかは 143。確定済み `season.jsonl` の `G`）に届くまでの試合だけを採る。ポストシーズンは試合数の上限で外れる。
- 照合1: 採った試合 11,028 件（864・858・720 試合の年に一致）から作った球団年の `G/W/L/T/RF/RA` は、確定済み `season.jsonl` の 156 球団年**すべてで一致**。
- 照合2: その試合表で `sakanalytics.py` を走らせ、確定済み `season.jsonl` と共通の 214 列 × 156 球団年 = 33,384 セルを比べると、33,382 が一致。違う 2 セルは 2013 年の `rf_low_streak` だけ（前の年 = 2012 年の試合が入力にないため）。`wave_*` はすべて一致。
- 試験の対照（今のコード vs 確定済み）: 156 単位、違う行 0（`wave_eps_trial_gate.json`）。
- 2012 年の試合は入力にないため、2012 年の行は結果に出ません（確定済みの 168 行のうち 156 行）。
- 注意: PR #127 の README が述べるとおり、`games_raw.json` は `games.jsonl` の代わりとして検証済みのものではありません。上の取り出し方は、この試験のためにローカルで行った変換で、QueRyu 側の変換として採用するものではありません。NPB の利用条件も未確認のままなので、派生した数値だけを置いています。

## 結果（要点）

- 減衰が 0 だった単位は 156 のうち **23**（11 球団、2013〜2024 年。2023 年の中日を含む）。確定済みでは、23 すべてで `wave_limit_rank` が空欄。
- ε = 1e-3, 1e-6, 1e-9 のどれでも、23 すべてで選ばれた式は ε の波のまま、`wave_limit_rank` と `wave_settle_x` が出る。
- 動き方: 最後の日の順位（`wave_end_rank`）のずれは ε にほぼ比例（最大 8.68e-4 / 8.68e-7 / 8.68e-10）。`wave_limit_rank` は 1.032〜5.946 の範囲で、ε によるずれは最大 0.00094 順位。`wave_settle_x` の中央値は ε を 1000 分の 1 にするごとに約 1000 倍（724.8 / 724,216 / 724,214,953）。落ち着く位置は 1/ε に比例し、ε → 0 で無限大。
- ε = 1e-3 では、減衰 0 でなかった 1 単位（2024 年のソフトバンク）が、ε の波に乗り換わる（減衰 0.5・周期 1/3 → 減衰 0.001・周期 0.25）。1e-6 と 1e-9 では乗り換えなし。ε が大きいと「境界でない単位」の選択まで動く、という材料。
- 減衰 0 でなかった単位への波及は、`wave_limit_rank_h1`（前半だけの当てはめ、空欄 33 → 0）と `wave_osc_base`（疑似シーズン側、3〜9 単位）に出る。

読み方の注意は `wave_eps_trial.md` の末尾と同じです。

## SakAnalytics 側の実装との照合

[SakAnalytics #24](https://github.com/myon-bioinformatics/SakAnalytics/pull/24) の `season_trajectory(..., wave_eps=ε)`（`wave_basis` を差し替えない、組み込みの ε）を同じ試合表で走らせ、この試験の行（`eps_*` 列）と比べると、3 つの ε のすべてで、10 列 × 156 単位の違いは 0。`wave_lifted` の数は ε = 1e-6・1e-9 で 23（= 上の 23 単位）、ε = 1e-3 で 24（乗り換えた 2024 年のソフトバンクを含む）。`wave_*` 以外の列は ε を渡さない場合と同一でした。
