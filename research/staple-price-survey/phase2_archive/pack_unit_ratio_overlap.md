## 方法

1. 同年・同品目家族で、脚注 a) 都市の年平均・月次 = **P10**。  
2. それ以外の都市（年平均 &lt; 3200 でフィルタ；未脚注の10kg疑いを除外）の平均 = **P5**。  
3. **R = P10 / P5**。¥/kg = P10/10 と P5/5。  
4. 都市構成の差が残る **cross-city 代理**である（同一店舗の袋サイズ比ではない）。
5. **しきい値 3200 は人が置いた値**である。外れ値を 10kg 側に入れた場合の R を併記する（下表）。

外れ値（5kg表示だが年平均≥3200）: 2003 徳島(1003)=3800、福島・金沢(1005); 2004 富山(1003)=3838 → `pack_unit_ratio_outliers.csv`。

## R をずらしたときの含意（グリッドは回していない）

定数 R で `P_yen = price_10kg / R` とするとき、÷2 基準に対する水準倍率は **2/R**。接続点の前年比だけが R に依存する（1999–2001 内部の YoY は定数比が相殺）。

| R | 接続年の K 倍率（vs ÷2） | 2001→2002 の前年比 |
|---|---|---|
| 1.8 | +11.1% | −8.8% |
| 1.9 | +5.3% | −3.7% |
| 2.0 | 0% | +1.4% |
| 2.05 | −2.4% | +3.9% |

（2001 raw 10kg = 4523.8、2002 pouch = 2293.3 から再計算。ユーザー表と一致。）

**二つの含意:**

1. **前年比（YoY）:** 1999–2001 年の中の前年比は定数 R が相殺される。R の影響は接続点（2002）の 1 点だけ。**グリッドは不要**；その点を除外または印付けすれば足りる。  
2. **水準:** 1999–2001 の K が 2/R 倍で一斉にずれる。ずれは `(3/n_train)×(2/R−1)`。**n_train=11** では R=1.8 → +3.0%（≈+63円 at P≈2100）、R=1.9 → +1.4%（≈+30円）、R=2.05 → −0.7%（≈−14円）。旧来の「1〜2%（20〜40円）」はおおむね **R=1.9** の話。レガシー版 aoff の 2020・2021 年勝ち差（約 **6〜19 円**）は R=1.8–1.9 なら大幅に、R=2.05 でも同程度に動くので、**水準の年勝は R の不確かさの範囲で反転し得る**。詳細は `pack_ratio_sensitivity_prelock_2026-10-24.md`。

## 解釈

1. ÷2 は **接続の約束事**として残してよい。**等単価が確認できたとは言えない**（実測幅 1.81〜2.03；cross-city 代理；外挿）。  
2. 2003–2004 は R が下がり、n10=2（津・松江）のみ。しきい値の置き方で下限は **1.81** まで下がる。  
3. item 1002 に同一年の両単位が無い、1999 の E は農林漁家除外、などの定義断絶のため、**1999–2001 を 5kg 連続パネルと均質に扱わない**。
