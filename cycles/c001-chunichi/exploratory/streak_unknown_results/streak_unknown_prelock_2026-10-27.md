**宣言時刻:** 2026-10-27（Asia/Tokyo）。正確な時刻とハッシュは `streak_unknown_prelock_timestamp.txt`。この文書を固定した時点では、スクリプトも計算も書いていない（§4 の数は、確定済みの出力を読んで数えただけ）。
**役割:** 実装・実行・判定の文章 = Claude。
**きっかけ:** 2026-10-27 のユーザーの方針。前の年が不明なとき、0 として数えず、変数か定数として扱って後から埋める。そこから命題を生むところまで、検証のパターンを試す。
**由来:** 同日のドラフト v1 に、ユーザーの決定 2 点（§7）を入れて固定したもの。

## 1. 問い

`streak()`（`inn_size_low_streak`・`rf_low_streak`）は、前の年が空のとき `(prev or 0) + 1` で 0 とみなしている。これを「未知の定数 u（0 以上の整数）」として扱うと、この列を使う命題（P62〜P65）の判定は変わるか。変わるなら、u のどの範囲で変わるか。

## 2. 定義

- 各 (チーム, 系列) で、旗（条件が成り立つか）が分かる最初の年を「左端」とする。`inn_size_low_streak` は 2013（2012 は試合が入力になく、旗が空）、`rf_low_streak` は 2012。
- 旗が成り立つ年が左端から途切れず続く連続は、観測した長さ n に未知の u を足した **n + u**（u ≥ 0）。左端に届かない連続は n で確定。旗が成り立たない年は 0 で確定。旗が空の年は空。
- **u は記号のまま。0 などの値を仮置きしない。**
- 条件 `streak op v` の三値（op は `>=`・`>`・`<=`・`<`・`==`・`!=`）:
  - n + u の真偽が、すべての u ≥ 0 で同じ: その真偽で確定
  - u によって真偽が変わる（左端に届く連続で、n のときと u が十分大きいときの真偽が違う）: **不明**

## 3. 評価のしかた

- 同じ評価の仕組み（`pythdragoras/propositions.py` の `evaluate`）に、列の値だけを変えた 3 つの表を渡す。
  - (a) 現状: 値はそのまま。u = 0 に当たり、確定済みの出力と同じ。
  - (b) u が十分大きい: 左端に届く連続の行の値を、十分大きい数にする。
  - (c) 不明な行を空にする: その命題のどの条件でも真偽が (a) と (b) で違う行の値を空にする。空の行は、評価の仕組みの「判定できない」の数に入る。
- `>=` や `>` で k = 2 のとき、n = 1 の行が真になるかは u ≥ 1 かどうかだけで決まる。なので (a) と (b) で、u のすべての値を尽くす（u を決めなくてよい）。
- 判定の読み: 各形の終了コードが (a)(b)(c) で同じなら「u によらない」。違えば「u しだい」と書き、分かれ目の行（チーム・年）を残す。
- 命題を生むレベル: u に関する命題として書く（例: 「P62 の原命題は u = 0 のとき終了コード 0、u ≥ 1 のとき 0 でない。分かれ目は l-2013」）。反例（判例）は、どの行が u によって前提を満たすかで示す。
