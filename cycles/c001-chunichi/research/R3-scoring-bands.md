# R3: 得点の不足はどの得点帯で生まれたか（研究計画）

記録: 2026-10-04。計算を始める前に書いた。指標（`rf_def_*`）は実データで一度も計算していない。

## 位置づけ

**探索的な研究。** R1・R2 の実データの結果を見たうえで書いている。
PR #3（GPT の R001）にも得点の分布の検討（SCORING_RESULTS.md、SCORING_SPREAD_RESULTS.md）があるが、**この計画を書く時点では読んでいない**。結果を出した後に照らし合わせる。

## 問い

R2 で、中日は失点を抑えた年でも得点の不足がそれを上回っていた。その不足は、

- 床: 0〜2点に抑えられる試合が多いこと
- 天井: 6点以上の大量得点が少ないこと

のどちらで多く生まれているか。それは他の低得点のチームと同じ形か。不足の形の違いは順位と関係するか。

## 方法

1試合の平均得点は Σ_{k≥1} P(得点 ≥ k) に等しい。同じ年・同じリーグの他球団の P(得点 ≥ k) の平均との差を k ごとに取り、帯に分けて足す。

| 列 | k の範囲 | 意味 |
|---|---|---|
| `rf_def_floor` | 1〜2 | 0〜2点に抑えられる試合の多さによる差 |
| `rf_def_mid` | 3〜5 | 中くらいの得点の差 |
| `rf_def_ceiling` | 6以上 | 大量得点の少なさによる差 |
| `rf_def_total` | 合計 | 得点／試合 − 他球団の得点／試合の平均（恒等式で一致する） |

近似も推定もない、分布の差の分け方である。帯の境（2と6）は計算前に決めた。

| 命題 | 内容 | 強さ |
|---|---|---|
| P19 | 低得点（得点5位以下）の年の中日は、床の不足が天井の不足より大きい | 概ね（0.75） |
| P20 | 低得点のチーム全体でも、床の不足が天井の不足より大きい | 半分より多く（0.50） |
| P21 | 低得点のチームの間では、床の不足が大きい形なら B クラス | 概ね（0.75） |

P19 と P20 の成立率を並べて、中日の形が低得点のチームの中で特別かを見る。

## 見直す条件（反証）

- P19 が成り立たない（中日の低得点の年の4分の1を超えて、天井の不足のほうが大きい）なら、「中日は抑え込まれる試合が多い」という見方を弱め、「大量点が出ない」側を調べる
- P19 と P20 の成立率がほぼ同じなら、中日の不足の形は低得点のチームに共通のもので、中日固有の説明にはならない
- P21 の lift が 1 に近い（Fisher の p ≥ 0.05）なら、不足の形は順位と関係せず、効くのは不足の総量だけ、という見方に戻る

## 限界

- ホームチームは勝っていれば9回裏を行わず、サヨナラでは決勝点で試合が終わる。ホームの勝ち試合の得点は低めに打ち切られ、天井の帯に偏りが入る
- 対戦相手の投手の強さ、DH の有無（セ・パ）、年ごとの得点環境は、同じ年・同じリーグの他球団と比べることでそろえるだけで、補正はしない（球場の係数も使わない）
- 帯の差は「どの得点帯で差が出たか」の記述で、「なぜ打てなかったか」（選手・打順・起用）の説明ではない

読めること（記述）:

- 中日の不足の形は、低得点のチームと同じ（床は同程度、中・天井が大きい）。**形は中日固有ではなく、総量が大きい**（−0.60 対 −0.44）
- 低得点で A クラスに入ったチームは、不足の総量が B クラスの約半分（−0.26 対 −0.52）。R2 の「得失点差が分かれ目」と同じ方向
- 計算後に見えたこと（命題にはしていない）: 中日 2021〜2024年は床の不足も −0.10〜−0.20 と、低得点のチームの平均（−0.08）より大きい。この4年は、どの帯でも不足していた

## 自分への異議（計算後）

**帯の幅がそろっていない。** 床は k = 1, 2 の2つ、天井は k = 6 以上のすべてを足す。得点への寄与で比べると、天井が大きく出やすい作りになっている。
P19・P20 の「天井の不足のほうが大きい」は「失った得点の多くは高い得点帯の分」という意味であり、「0〜2点で終わる試合が少ない」という意味ではない。

PR #3（GPT R001）の SCORING_RESULTS.md は、同じ期間を**試合の頻度**で見ている。中日は2点以下で終わる試合が 44%（他のセ5球団は 35〜40%）、0〜1点の試合の割合はホームで6球団中最多。
これは今回の結果と矛盾しない。0〜2点の試合が多くても、その1試合で失う得点は2点までなので、得点の差への寄与は小さく出る。

したがって、言い方は次のように分ける。

- 頻度で見ると: 中日は「抑え込まれる試合」が他球団より多い（PR #3）
- 得点の量で見ると: 中日が失った得点の多くは、3点以上取る試合が少ないことから来ている（R3）

どちらも「打てない」の一つの面で、どちらが原因かはこの観測では決まらない。次に分けるなら、イニング単位（得点する回の頻度と、得点した回の点数。PR #3 の INNING_METRICS.md の定義）が必要になる（H5〜H7 の保留を解く）。
