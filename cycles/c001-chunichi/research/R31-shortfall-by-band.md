# R31: 中日の得点の不足は、どの帯で、どれだけ大きくなったか（研究計画）

記録: 2026-10-05。計算を始める前に書いた。スクリプト [r31_balance.py](r31_balance.py) は書いたが、まだ実行していない。

見ているもの: R3 の期間平均（中日の低得点の年 11単位で床 −0.08・中 −0.24・天井 −0.28・合計 −0.60）と、R3 の計算後の記述「2021〜2024年は床の不足も −0.10〜−0.20」。R29・R30 の結果（中日の片側だけ上位の B は 2019年を除いて得失点差マイナス、2021〜2023年は −73〜−108）。年ごとの帯の値の表、失点の優位の値は見ていない。

## 位置づけ

R29・R30 で、中日の問いは「なぜ失点1〜3位でも得失点差がプラスにならなかったか」（得点の不足の大きさ）に戻った。2021〜2023年は不足が年を追って大きい。ここでは、

1. 不足が大きくなったのは、どの得点帯か
2. 失点の優位で、得点の不足をどれだけ補えたか

を年ごとに並べる。**記述の研究**で、命題は登録しない（不足と優位の大小は、得失点差の符号とほぼ同じことを言うので、命題にしても R29 の繰り返しになる）。

## 方法

- 帯は R3 の定義のまま（1試合あたり、同じ年・同じリーグの他球団の平均との差）: 床（0〜2点）、中（3〜5点）、天井（6点以上）、合計
- 失点の優位 = 同じ年・同じリーグの他球団の失点／試合の平均 − 中日の失点／試合
- 収支 = 得点の不足（合計）+ 失点の優位。プラスなら、失点で得点の不足を補えた
- 期間は先に決める: 2013〜2019年と 2021〜2025年（2020年は除く）

```bash
python cycles/c001-chunichi/research/r31_balance.py cycles/c001-chunichi/outputs/season.jsonl
```

## 読み方（先に決める）

1. **拡大の中心**: 得点の不足（合計）の2つの期間の差のうち、ひとつの帯が 50% 以上を占めるなら、その帯を拡大の中心と書く。どの帯も 50% 未満なら「どの帯でも広がった」と書く
2. **補えた幅**: 失点だけ上位の B クラスについて、中日と中日以外で「不足 ÷ 優位」の平均を並べる。中日のほうが 0.2 以上大きいなら、中日は**失点の優位に対して得点の不足が特に大きい**側と書く
3. 2つ目の期間で失点の優位が1つ目の期間より大きいなら、「投手は良くなったのに、打撃の不足がそれ以上に広がった」と書く。小さいなら、両方が悪くなったと書く

## 限界

- 帯の幅がそろっていない（R3 の自分への異議）。天井は大きく出やすい
- 失点の優位は失点の総量だけで、守備と投手は分けない
- 記述であり、「なぜ打てなかったか」（選手・起用）は言わない

### 計画からの変更（実行後）

計画では「不足 ÷ 優位」を**単位ごとの比の平均**で並べると決めていた。実行すると、失点の優位がほぼ 0 の単位（中日 2023年 +0.02 など）で比が発散し、中日以外の平均は意味をなさない値になった。**平均の比**（不足の平均 ÷ 優位の平均）に置き換えた。読み方 2 の基準（0.2 以上）はそのまま当てはめる。

### 1. 拡大の中心: どの帯でも広がった

- 得点の不足は 2013〜2019年の −0.39 から、2021〜2025年の −0.83 へ、1試合あたり −0.45 広がった
- その割合は、中（3〜5点）47%、床（0〜2点）28%、天井（6点以上）25%。50% を超える帯はないので、計画の読み 1 により **どの帯でも広がった**と書く（いちばん大きいのは中）
- 床は 2013〜2019年はほぼ 0（−0.02）だったのが、2021〜2025年は −0.15。**抑え込まれる試合の多さが、後の期間で新しく加わった**（R3 の計算後の記述と同じ向き）

### 2. 補えた幅: 中日が特別かどうかは、割り算のやり方で変わる（決めない）

- 平均の比では、中日 2.29、中日以外 2.67。中日のほうが小さく、計画の読み 2 の「中日が 0.2 以上大きい」には当たらない
- 中日は得点の不足が大きい（−0.64 対 −0.48）が、失点の優位も大きい（+0.28 対 +0.18）
- ただし下の「0 の近くの割り算」で、割り方を変えると差の向きが入れ替わる（比の中央値では中日 2.41・中日以外 2.18 で、中日のほうが 0.23 大きい）。**中日が特別に大きいとも小さいとも言わない**

### 0 の近くの割り算（ユーザーの指摘を受けた追記、2026-10-05）

割る数（失点の優位）が 0 に近い単位があると、比の平均は発散する。平均の比への置き換えはその場しのぎの1つで、ほかにも形がある。どれが正しいかは決めず、**読みがどの形でも保たれるか**を見る。

| 失点だけ上位の B | 比の平均（計画） | 平均の比 | 比の中央値 | 自然対数で平均（幾何平均） | 取り分の平均 → 比 | 外した単位 |
|---|---|---|---|---|---|---|
| 中日（6） | 11.1 | 2.29 | 2.41 | 3.12 | 0.69 → 2.19 | 0 |
| 中日以外（17） | 3.7×10¹³（発散） | 2.67 | 2.18 | 25.5 | 0.70 → 2.39 | 3 |

| 形 | 中身 | 0 の近くで |
|---|---|---|
| 比の平均 | 単位ごとの不足 ÷ 優位の平均 | 発散する（優位がちょうど 0 の単位が1つある） |
| 平均の比 | 不足の平均 ÷ 優位の平均 | 範囲全体の優位が 0 に近くなければ安定 |
| 比の中央値 | 単位ごとの比の中央値 | 発散した少数の単位に引っ張られない |
| 自然対数で平均 | exp（平均 ln（不足 ÷ 優位））。大きな比を圧縮する | 対数は正の値にしか使えず、優位 ≤ 0 の3単位を外す。0 にごく近い正の単位は、対数でも大きく残る（25.5） |
| 取り分 | 不足 ÷（不足 + 優位）。0〜1 に収まり、優位 ≤ 0 なら 1。平均を s ÷（1 − s）で比に戻す | 発散しない |

読めること:

- 中日と中日以外の差は、発散しない形（平均の比・中央値・取り分）で −0.38〜+0.23。**向きが定まらない**
- 自然対数は大きな比を縮めるが、0 そのものと負の値は扱えない。0 を含む符号つきの値には、取り分のように**範囲が決まった形**か、中央値のように**順位で読む形**のほうが向いている
- 一般の規則（`docs/` のマスター）にするかは、ほかの研究で同じ問題が出たときに決める。今は R31 の記録にとどめる

### 3. 投手は良くなったのに、打撃の不足がそれ以上に広がった

- 失点の優位は 2013〜2019年 +0.03、2021〜2025年 +0.14。計画の読み 3 により、**投手は良くなったのに、打撃の不足がそれ以上に広がった**と書く
- 収支は −0.36 から −0.69 へ悪くなった
