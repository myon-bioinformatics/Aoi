# 失点増の上積みを分解し、異議を終了コードで残す

## 結果

中日の2013〜2025年平均で、ビジターとホームの失点差は **+1.076点／試合**。各試合の失点を「6点まで」と「6点を超える部分」に分けると、次のとおりだった。

|成分|ビジター−ホームの差|平均差に占める割合|
|---|---:|---:|
|各試合の失点を6点で打ち止めにした成分|+0.773|71.9%|
|各試合で6点を超えた分だけの成分|+0.303|28.1%|
|合計|+1.076|100%|

2020年を除いても、合計+1.042、6点まで+0.721、超過分+0.321となる。

ここでいう「6点まで」は大量失点試合の最初の6点も含む。**「差の71.9%が少失点の試合から生じた」とは言えない。** 6点超過分だけで失点差の大部分を説明する見立ては、この定義では支持されなかった。これだけで全試合に広く悪化があるとも断定しない。試合ごとの度数と各閾値の超過確率を保存したので、その観測へ進める。

境界の選択への依存を隠さないため、0〜22点の全境界を出力した。中日の平均失点差のうち境界超過分は、3点で+0.734、4点で+0.581、5点で+0.441、6点で+0.303、8点で+0.108、10点で+0.021。「過半か」は4点と5点の間で変わる。6点の採用は探索上の仮定であり、普遍的な大量失点の定義ではない。

## PythDRAgoraS に渡した命題

`R001-T1`: 「ビジター平均失点がホームより多い球団年では、その差の過半は6失点を超える部分に現れる」。新しい集計を実行する前に `tail_propositions.toml` に固定した。対象は2013〜2025年のセ6球団・78球団年。全称の強さはこの観測済みの有限表についてであり、母集団法則の主張ではない。

|形|条件該当|成立|反例|既存エンジンのコード|
|---|---:|---:|---:|---:|
|元の命題|48|9|39|3|
|対偶|49|10|39|3|
|逆|29|9|20|3|
|裏|30|10|20|3|

元の命題と対偶、逆と裏はそれぞれ反例集合が一致した。元の命題は反例により不成立。中日は全13年でビジター平均失点が多く、6点超過分が過半となるのは2014・2025年の2年で、11年は反例だった。これも元の探索仮説として残し、支持されるように境界や対象年を変更しない。

既存エンジンのJSONにはWilson区間等も出るが、球団年は試合を共有しており独立標本ではない。この研究では母集団に対する有意性の証拠として使わない。

## 逐次実行と終了コード

```sh
python research/gpt-r001-score-allocation/run_loss_tail.py
```

実測は次の順序で完了した。

|段階|実行内容|終了コード|
|---|---|---:|
|tests|研究用15テスト。意図的な入力欠落・不正引数・不正データ・反例を含む|0|
|analysis|入力照合、度数・全境界集計、恒等式の照合|0|
|judgement|PythDRAgoraS の元・対偶・逆・裏の判定|3|
|逐次実行全体|最後の命題判定を保持|3|

`0` を得るために反例を消すことはしない。テストの `0` は「不成立を3で返す動作も含め、期待した挙動を確認できた」。命題の `3` は「観測に反例があり、置いた主張は成立しない」。両者は別の意味を持つ。

判定は既存 `PythDRagoras/logic/propositions.py` の `load/evaluate` を直接利用し、研究側で判定規則を再実装していない。エンジンのコードハッシュも保存する。命題側の0〜6と、引数・命題64、データ65、入力欠落66、実装70、出力I/O74を区別する。テスト／集計段階で非0ならその場で止まり、命題評価まで進めない。標準出力・標準エラー・子プロセスの終了コードは `outputs/loss_tail_sequential.json` に保存する。

個別実行も可能。

```sh
python research/gpt-r001-score-allocation/loss_tail.py analyze
python research/gpt-r001-score-allocation/loss_tail.py judge
```

集計は引分を含む全公式戦を使う。失点の整数値ごとの頻度を保持し、P(失点≥k)のホーム／ビジター差を全kで足すと平均失点差へ戻ることを78球団年で確認した。入力は既存の独立年度照合を通過したものだけを受け付ける。判定対象表はハッシュで集計受領記録と照合する。

## 次に残ること

今回の仮説は「負け試合を早く諦めたから大差になった」などの行動を直接調べたものではない。負け試合かどうかで選別せず、まず全試合の失点を分解した。次は頻度表から、たとえば低失点に抑えた機会が減っているのか、どの点数帯へ移っているのかを全範囲で確認できる。球場係数の作成は必要条件にしない。

この結果は「14年間 CS 不出場」の最終回答ではないが、ビジター失点増について一つの説明候補を具体的に棄却し、次に区別すべき現象を狭めた。2026年・イニング・起用は未検証のまま区別している。
