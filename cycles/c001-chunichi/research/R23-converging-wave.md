# R23: 順位の線を、始まりの値から収束していく波で表す（研究計画）

記録: 2026-10-04。計算を始める前に書いた。`wave_*` はこの計画のために作った列で、実データではまだ計算していない。
R22 の結果（3次式の形・山の位置、中日の年ごとの形）は見ている。

## 位置づけ（ユーザーの見立て）

- 開幕直後の揺れは、ウォームアップと減衰（ディケイ）のようなもの。線を引き始める「全球団が10試合」の 10 は変えられるようにし、指標として「何試合を終えた段階からの線か」を言えるようにする
- 波は sin・cos・フーリエ、どれでもよい。焦点は、ゆらぎをどう当てるか
- **切片は置かない**。切片を置くと、その範囲をまた考えることになる。決まった試合数を終えた段階の値を始まり（初期値）にして、そこから波打たせる
- 見たいのは**徐々に収束していく様**。シーズンの終わり（あるいは無限の先）へ飛ばしたとき、特定の値に行けるか。式は連続で微分できるものなら何でもよい

## 方法

### 線の始まり（変えられる設定）

[analysis.toml](../analysis.toml) の `[trajectory]` の `min_games`（今回は 10）。リーグの全球団がこの試合数に届いた日から線を引く。結果には `traj_start_games`（試合数）・`traj_start_x`（シーズンの中の位置）・`traj_start_date`（日付）が残る。

### 式: 始まりの値から出発して、減衰しながら波打つ

順位の高さ h（6球団なら 1位 = 6、6位 = 1）の線に、

```text
h(x) = L + e^(−λt) · ( (h0 − L)·cos(ωt) + B·sin(ωt) )      t = x − 線の始まり
```

を当てる。

- **h0 は線の始まりの日の実際の値**で、当てはめで動かさない（切片を置かない）。x = 始まりでは必ず h = h0
- **L は収束する先**。λ > 0 なら、t が大きくなるほど h は L に近づく（シーズンの終わりの先へ飛ばした極限）
- λ（減衰の速さ）と周期（2π/ω）は決まった格子から選ぶ: λ = 0, 0.5, 1, 2, 3, 5, 8, 13、周期 = なし, 2, 1, 0.75, 0.5, 1/3, 0.25（シーズンの何割で1周するか）。L と B は最小二乗で決まる。同じ当てはまりなら、波なしで近づく → 減衰する波 → 減衰しない波、の順に簡単なほうを選ぶ
- どの格子でも連続で微分できる。λ = 0（減衰しない）が選ばれたら「収束しない」で、L は空にする

### 読む量

| 列 | 中身 |
|---|---|
| `wave_limit_rank` | 収束する先を順位に直したもの（減衰しなければ空） |
| `wave_end_rank` | 最後の日の値（順位） |
| `wave_settle_x` | **順位が決まった位置**: ゆれの幅 e^(−λt)·√((h0 − L)² + B²) が半順位を下回る位置。1 を超えればシーズン中には決まっていない |
| `wave_limit_rank_h1` | **前半（横軸 0.5 まで）の線だけ**から当てた波の行き先（前半で、もう行き先が見えていたか） |
| `wave_settle_pct` | 力が一定のシーズン（R22 と同じ 200回）のうち、順位が決まった位置が実際より早かった割合（小さいほど、実際のほうが早く決まった） |
| `wave_osc` / `wave_osc_base` | 波のある式が選ばれたか / 力が一定のシーズンで波のある式が選ばれた割合 |

## 読み方（先に決める）

1. **特定の値に行けるか**: 中日の年ごとに、収束するか（λ > 0）、収束する先（`wave_limit_rank`）、最後の日の値、実際の最終順位を並べる（記述）。全体で、収束した単位の割合と、収束する先が実際の最終順位から1未満の単位の割合を数える
2. **いつ決まるか**（P102・P103）: 力が一定なら、`wave_settle_pct` < 0.5 は半分ほどの単位で起きる。P102 が支持（区間の下端が 0.5 を超える）なら、**中日の B クラスの順位は、力が一定のときより早く決まっている**。P103 との差が 0.2 以上なら中日に寄った形、0.2 未満なら B クラスに共通
3. **前半で行き先が見えていたか**（P104・P105）: P104 が支持なら、中日の B クラスの年は前半の線だけでもう4位以下に向かっていた。P105 との差が 0.2 以上なら中日に寄った形
4. **波で表せるか**: 波のある式が選ばれた数を、力が一定のときの見込みと比べる（`trajectory_expectation.jsonl` の `wave_osc`）。見込みより多く P < 0.05 なら、力が一定のときのゆらぎを超えた波がある。そうでなければ、波は力が一定のときにもできるゆらぎの範囲（R22 と同じ読み方）

## 限界

- 格子の上で選ぶので、λ と周期は格子の値のどれかになる（細かい値は求めない）
- 波のある式は B の分だけ形を合わせやすいので、力が一定のときも選ばれやすい。だから必ず基準と比べる
- 順位は他のチームの成績でも動く（R22 と同じ）
- 線の始まりを変えると結果も変わりうる。今回は 10試合だけで読み、ほかの値は試さない（試すなら新しい計画にする）

## 結果（2026-10-04、Actions の実行 37172965995。npb.jp へのリクエストは 0）

### 2. いつ決まるか（P102・P103）

| 命題 | 結果 | exit |

## 読めること

1. 10試合を終えた段階の順位から出発して減衰する波は、94% の年で**実際の最終順位に向かって収束する**。順位の線は「始まりのゆれが減衰しながら、決まった位置へ落ち着く」形で表せる
2. 中日の B クラスの年は、その落ち着く先がいつも4位以下で、**落ち着くのが早い**（中央値でシーズンの3割、5月下旬ごろ）。他の B クラスのチームより早く、とくに 2018年以降は毎年、力が一定のときより早く決まっていた
3. 波の形や周期そのものは、力が一定でもできるゆらぎの範囲。読めるのは「どこへ・いつ落ち着くか」の側
4. R20（前半からすでに4〜6位）、R22（山も谷もなく下がり続ける）と合わせると、中日の B クラスは**シーズンの早いうちに位置が決まり、そこから動かない**。B クラスの理由は、シーズンの途中の崩れではなく、始まる前からの水準（R4・R14）の側にある

## 追記: 線の始まりを変えたとき（R25）
