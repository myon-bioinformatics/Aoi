## 0. 設定

- 式の共通部分: \(q=5\)（5kg袋）、\(E\)=エンゲル係数（小数）、\(A\)=青木率（内閣＋与党第一党）
- 訓練: **2015–2021**（n=7）。係数は訓練窓のみで推定・凍結。
- ナイーブ: \(\hat P_t = P_{t-1}\)
- 指標: 価格（円）の MAE / 中央絶対誤差

| form id | 式 | 役割 |
|---|---|---|
| `primary_100` | \(P=K\cdot q\cdot(100-A)\cdot E\) | primary（現行） |
| `alt200` | \(P=K\cdot q\cdot(200-A)\cdot E\) | **比較用のみ**（ε的シフト。primaryにしない） |
| `exp_ols` | \(P=K\cdot q\cdot e^{-\beta A}\cdot E\) | β,K を訓練で log線形OLS |
| `prop_A` | \(P=K\cdot q\cdot A\cdot E\) | 反対符号（P∝A） |
| `exp_plus_constrained` | \(P=K\cdot q\cdot e^{+\beta A}\cdot E\), \(\beta\ge0\) | 反対符号（自由傾き≤0なら β=0＝Aなし） |
| `exp_fixed_beta_*` | β∈{0.01,0.02,0.05,0.1} 固定、K=訓練平均 | 二次（感度） |

**OLS（exp）:** \(\log(P/(q E)) = c - \beta A\)。訓練で \(c,\beta\) を自由推定。\(\hat K=e^{c}\)。

**過学習注意:** パネル全体 n=11、訓練 n=7。Kとβを同時に動かす余地は小さく、勝敗は参考値。

## 3. 反対符号（四形態の向き）

草案の向きは「Aが高い → 価格が下がる」（shellがAで縮小）。反対は P∝A または \(e^{+\beta A}\)。

| form | holdout MAE (naive 264) | full OOS MAE (naive 676) | 解釈 |
|---|---:|---:|---|
| prop_A（P∝A） | 496（負け） | 1029（負け） | 反対の掛け殻は両窓で敗北 |
| exp_plus β≥0 | 223（勝ち※） | 756（負け） | 自由OLSの傾き s=−0.006→制約で **β=0（A削除）**。Aの反対符号推定ではない |
| exp_ols（−β、推定β>0） | 130（勝ち） | 651（辛勝） | 符号は草案どおり（高A→やや安）だが効果は極小 |

**訓練OLS:** \(\hat\beta = 0.006038 > 0\)（\(s=\partial\log(P/(qE))/\partial A = -0.006038\)）。向きは草案と同じだが、Aが30pt動いても \(e^{-\beta\Delta A}\approx 0.83\) 程度の弱い減衰。`(100−A)` の約3倍振れとは桁が違う。

## 4. 固定β感度（二次）

βを大きくするほど悪化。β=0.01 付近だけ holdout / full で辛勝し、OLS推定（0.006）と同帯。β≥0.02 は両窓で敗北。→ 「強く効かせた政治項」はデータに合わない。

---

## 5. 判定（Claude案の分岐に沿う）

対象は比較の主対象3形: **primary_100 / alt200 / exp_ols**。

| 窓 | 前年に勝つ形 | 判定 |
|---|---|---|
| holdout 2022–2024 | alt200, exp_ols（primaryは負け） | **効き方は形に依存する** |
| baseline 2022–2025 | alt200, exp_ols（primaryは負け・両者とも辛勝） | **効き方は形に依存する** |

### 一行結論（Claude共有用）

**`(100−A)` primary は両OOSで前年ナイーブに大敗。比較用 `(200−A)` と推定β≈0.006の exp形は2022–2024では勝つが、2025単年では両者ともナイーブに負け、フルOOSでは辛勝に留まる。よって「形に依らず使えない」とは言えない一方、primary殻のままでは使えず、勝ちは形依存（かつ alt200 はε的比較用・expのβは極小）。反対符号の P∝A は両窓敗北。n=7訓練のため次は命題化（softplus(50−A) 等）か多国前に日本で形を絞る判断が必要。**

### 補足（採用上の注意）

1. **alt200 を primary に昇格しない**（ゼロ付近を200にずらしただけ／εと同型）。
2. **exp_ols のβは実質ほぼフラット** — 「青木率が価格を動かしている」というより、\(q\cdot E\) スケール＋ごく弱いA補正。
3. **2025は構造変化候補** — 除外窓と含有窓で「勝ちの厚み」が全く違う。
4. **Aなし（β=0）** でも holdout ではナイーブに勝つ → 政治項なしベースラインを正式に併記すべき。
