# R36: 中日 2019年は、同じ形で A に入ったチームと何が違ったか（研究計画）

記録: 2026-10-05。計算を始める前に書いた。スクリプト [r36_case.py](r36_case.py) は書いたが、まだ実行していない。

## 位置づけ

R35 で、得点がはっきり足りず失点ははっきり上回る形（誤差の幅で得点 −1・失点 +1）は、中日以外で11単位、そのうち A が5（阪神 2013・2019、ソフトバンク 2012・2019、西武 2022）だった。中日 2019年はこの形で、得失点差もプラス（+19）なのに5位。ユーザーの依頼で、2019年を同じ形のチームと並べ、理由を探す。

見ているもの: 中日 2019年の `wins_vs_pythag`（−4.71）、阪神 2019年の `wins_vs_pythag`（+3.7）、R12〜R17 の 2019年の読み（強い相手から点が取れない P76、強い相手との試合全体の点が少ない P80）。ほかの指標の11単位の値は見ていない。

## 方法

1対5の事例の比べなので、命題の判定ではなく**記述**にする。並べる指標を先に決める（スクリプトの `MEASURES`）。

| まとまり | 指標 |
|---|---|
| 点の差を勝ちに変えたか | `wins_vs_pythag`、`one_run_net`、`blowout_net`、`alloc_z_strat` |
| 相手の強さ別 | `vs_top_wpct`、`vs_lower_wpct`、`opp_conv_top/mid/low`、`opp_net_gap_top_c`、`opp_env_gap_top_c` |
| シーズンの流れ・並び | `course_wpct_diff`、`series_lost_pct` |

## 読み方（先に決める）

1. 中日 2019年が、**A の5単位の範囲（最小〜最大）の外**にある指標を「2019年の差」とする
2. そのうち、**A の5単位と中日以外の B の6単位が重ならない**指標は、この形のチーム一般の A・B の分かれ目の候補。新しい id で命題にし、2026年で確かめる（見た後の命題なので、同じデータでは確かめにならない）
3. 2019年の差が A と B で重なる指標なら、**2019年に寄った差**として記録するだけにする
4. 2019年がどの指標でも A の範囲の内側なら、「同じ形の A と区別できる指標は、ここにはない」と書く

## 限界

- 事例は1つ、比べる相手は5つ。差は「並べたら外れていた」以上の意味を持たない
- 13の指標を並べるので、どれかが偶然外れることはありうる（13個のうち1〜2個が外れても、それだけでは何も言わない）

### 読み

1. **2019年の差（A の範囲の外）は 13 のうち 8**。計画の限界で書いた「偶然 1〜2 個」より多い。2019年は、同じ形で A に入ったチームとは、多くの面で違っていた
2. **A と B が重ならない指標は1つだけ: 上の相手（最終順位の1・2位）との勝率**（`vs_top_wpct`）。A の5単位は .48〜.57、B の6単位は .34〜.46。中日 2019年は **.45 で B の側**。計画の読み 2 により、命題 P143 として登録し、2026年で確かめる
3. ほかの7つ（点の差を勝ちに変えたか、1点差、組み合わせ方、下の相手との勝率、下の相手との変換、上の相手との点の差と点の多さ）は、A と B が重なる。計画の読み 3 により**2019年に寄った差**として記録する。どれも 2019年は B の範囲の中にいて、**同じ形の B のチームと同じ向きに外れていた**

### 2019年に何が起きたか（記述をつなげたもの）

| 面 | 2019年の中日 | 同じ形で A に入ったチーム（中央値） |
|---|---|---|
| 上の相手との勝率 | .45 | .52 |
| 上の相手との試合の点の差（見込みとの差） | −44点 | +11点 |
| 上の相手との試合全体の点の多さ | −70点（両チームとも点が入らない） | −24点 |
| 1点差の勝ち − 負け | −8 | +1 |
| 点の差から見込まれる勝ち数との差 | −4.7勝 | −0.3勝 |

- 失点を抑える形は同じでも、A に入ったチームは**上の相手に勝ち越すか五分**だった。2019年の中日は上の相手との試合が極端な投手戦になり（R17・R19 と同じ）、その投手戦で点の差まで負けた
- 接戦（1点差）でも 8 つ負け越し、点の差から見込まれるより 4.7 勝少なかった。得失点差がプラス（+19）でも5位になったのは、**勝ちに変えるべき試合（上の相手との投手戦、1点差）を落とした**から、と読める
- 下の相手にも .48 で勝ち越せなかった（A の5単位はどれも .51 以上）

## 命題（見た後）

P143（`propositions.toml`）: 得点 −1・失点 +1 の形で、上の相手との勝率が .47 以上なら A クラス。境 .47 は A の最小 .48 と B の最大 .46 の間をとった。同じデータでは確かめにならない（範囲の12単位をすべて見ている）。2026年で確かめる。

注意: `vs_top_wpct` の「上の相手」は**最終順位**で決めている。A のチーム自身が上の相手の1つと入れ替わる関係にあるので、A かどうかと算術でつながる面がある（上の相手に勝てば、その相手の順位を下げ、自分の順位を上げる）。
