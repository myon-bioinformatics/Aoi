# 連続年数の「前の年が不明」を記号 u にしたときの判定（探索・事後）

[`../streak_unknown.py`](../streak_unknown.py) を、確定済みの出力に当てた結果です。確定済みの出力と SakAnalytics は変えていません。宣言は[`streak_unknown_prelock_2026-10-27.md`](streak_unknown_prelock_2026-10-27.md)（固定の時刻と sha256 は[`streak_unknown_prelock_timestamp.txt`](streak_unknown_prelock_timestamp.txt)）、スクリプトと予想は結果より先に push してあります。

`streak()` は前の年が空のとき 0 とみなして数えています。左端に届く連続の値 n を「n + u（u ≥ 0 は未知）」として、評価の仕組みに (a) u = 0（現状）、(b) u が十分大きい、(c) 不明な行を空にする、の 3 つの表を渡しました。u の値は決めていません。数値は[`streak_unknown.json`](streak_unknown.json)、全部の表は[`streak_unknown.md`](streak_unknown.md)にあります。

## 入力

- `cycles/c001-chunichi/propositions.toml`（sha256 `0074801d0ede337a76c98624e8d206912ad0ee42a89fecde9d8eb7646d52a35a`。保存された結果の記録と同じ）

## 結果

各セルは「終了コード・hold/n（判定できない単位）」。終了コードは 0 異議なし、1 例外あり、2 主張が強すぎる、4 判断保留、5 判定できない単位。

## 読み（この入力で）

- **P62 の原命題と対偶の「異議なし（終了コード 0）」は、西武の 2012年に `inn_size_rank` が 2 以下でなかった、という 1 つの想定に依っています。** 西武の 2012年が下位 2 位以内なら（u ≥ 1）、l-2013（西武 2013、2位で A クラス）が判例になり、終了コードは 0 でなくなります。u を十分大きくしたとき（b）に判例が増える行は、この 1 行だけで、終了コードは 1 です。ほかの 3 行（d・s・b）は B クラスで、成立の側に加わるだけです。不明な行を空にすると（c）、原命題と対偶は「判定できない単位」（終了コード 5）になります。
- **P63 は原命題が 7〜10 単位で判断保留（4）のまま**、u によらず同じです。対偶だけが P62 と同じく u しだい（0 → 1 → 5）で、分かれ目も l-2013 です。
- **P64・P65 は終了コードが u によらない。** 不明な 4 行（2012年）で数は動きますが（原命題は 17〜30 単位）、原命題は判断保留（4）、対偶は例外あり（1）のまま (a)(b)(c) で変わりません。
- 逆と裏は P62〜P65 のすべてで終了コード 2 のまま（u によらない）。(b) では、2013年の B クラスの行（d・s・b）が逆の判例から外れ、判例の数が減ります。
- 命題として書くと、「西武の 2012年が下位 2 位以内だったなら、P62 の原命題は終了コード 0 でない」です。これを決める事実は 2012年の西武のイニング集計で、いまの入力にはありません。

## 限界・していないこと

- u は記号のままです。(b) は「u が十分大きい」で、k = 2 の条件では u ≥ 1 と同じです。**行ごとに u ≥ 1 かどうかを変えた組合せ（l-2013 だけを u ≥ 1 にするなど）は評価していません。** 全部の行を動かす (b) と、全部を動かさない (a) の両端だけを見ています。
- 見たのは、台帳の閾値（k = 2）で、P62〜P65 の 4 命題、1 つの入力です。k を振ることはしていません（宣言 §6）。
- 左端に届く連続は、確定済みの表の値から数えました（連続の始まり = 年 − n + 1 が、そのチームで列が空でない最初の年と同じ行）。2012年の試合は取っていません。
- 確定済みの出力、台帳、SakAnalytics の `streak()` は変えていません。「観測した長さ」と「左端で切れている印」の 2 列に分けるかは、この結果を見てあなたが決めることです。
