# Numbeo staples / restaurant basket — crowd-sourced country snapshot

- **Panel:** `numbeo_staples_restaurant_crowd_panel.csv`
- **What:** Country median prices (USD display) for 7 items: Coke/Pepsi 0.33L, McMeal, bread 500g, milk 1L, eggs ×12, cappuccino, inexpensive restaurant meal.
- **Source:** Numbeo public country price rankings HTML (geochart `addRows` data).

- **Coverage:** ~100+ countries per item; **current cross-section only** (retrieved 2026-10-25).
- **License / terms:** Numbeo Terms of Use; personal/research use of public pages. Historical bulk download and API are **premium / paid** — not used.
- **Caveats:** **CROWD-SOURCED**, not official NSO. Sample size and contributor bias vary by country. USD is site display currency. Do not treat as Big Mac–grade audited series.
- **Retrieved:** 2026-10-25 (Asia/Tokyo box).
