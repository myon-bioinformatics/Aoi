# ε の汎用性の確認: 野球以外の連続データで使えるか（探索・事前登録）

ε（波の減衰 0 を置き換える小さな値）の扱いは、ここまで中日・NPB の順位の線（`cycles/c001-chunichi/exploratory/wave_eps_*`）だけで見てきました。この文書は、**走らせる前に**、野球以外の連続データで ε が使えるかを何で判断するかを書いたものです。結果を見て基準を変えません。結果は `results/` に、この文書とは別に置きます。

ε の値は暫定の置き場所で、結論には使いません（ε は記号。値と扱いは今後決める）。

## 見ること・見ないこと

- 見る: `sakanalytics.wave_basis` の「減衰 0」の格子を ε に差し替える方法（`wave_eps_trial.make_wave_basis`）が、野球以外の連続データでも、(1) 差し替えた先が選ばれ、収束する先と落ち着く位置が有限の値で出る、(2) 落ち着く位置を「係数 × 10^n」（ε = 1 × 10^-n）と書いたときの係数が ε によらない、(3) 減衰 0 でない単位の結果を動かさない、か。
- 見ない: 野球の列（`wave_osc`、`wave_limit_rank_h1` など、順位・試合・季節に結びついた派生の列）。ε を別の場所で使うこと（`log(1+x)` を使う指標、θ = 0 や空欄の置き換え、青木率の端の ε）。これらは別に確かめる。
- ε の意味は x の単位で決まる: 位置 ≈ 係数 / ε なので、「ε = 1e-6」は「窓の長さの 10^6 倍先」を指す。ここでは x を窓の長さで [0, 1] にそろえるので、ε は窓の長さに対する値。別の x の単位で使うときは、どの長さに対する ε かを先に決める必要がある。

## 入力

### 実データ: 主食価格の月次の系列

`research/staple-price-survey/staple_survey_vertical.csv` の `staple_price:*` の行（61,157 行、5 つの出どころ: FAO FPMA、WFP の 2 つのファイル、米国 BLS、日本 e-Stat）。

- 系列 = (国, 変数, 単位, 出どころ, 注) の組。注には市場・価格の種類が入っているので、同じ月が 2 つの行にならない（なれば止まる）。通貨は出どころのまま（為替の換算はしない）
- 月 = 日付の年と月（日にちは無視する。WFP の年次ファイル由来の 5,029 行は 15 日の日付）
- 窓 = 月が途切れずに続く区間ごとに、先頭から N か月ずつ、**互いに重ならない**窓を並べる（余りは使わない）。N = 12, 24, 48。**主な窓は 24 か月**
- 窓の値の幅（最大 − 最小）が 0 の窓は使わない（数だけ記録する）
- 正規化: x を [0, 1]（窓の最初の月が 0、最後が 1）に、y を「最初の月が 0、幅が 5」にそろえる（`(v − v0) × 5 / (max − min)`）。幅 5 は野球の順位（1〜6 位）の幅

## 事前登録: 基準

「決まった」とみなす幅 τ は 0.5（値の幅 5 の 10%。野球の半順位と同じ大きさ）を主とし、0.25 と 1.0 も動かして記録する。ε は 1e-3, 1e-6, 1e-9。

用語: **境界の単位** = 今のコード（ε なし）が減衰 0 の式を選んだ単位。**係数** = 落ち着く位置 × ε（始まりの時点で決まっていた単位 = 位置が窓の最初と同じ単位は、係数なし）。

| 基準 | 内容 | 満たす条件 |
|---|---|---|
| C1 | 境界の単位で、ε を入れても ε の波が選ばれ、収束する先と落ち着く位置が有限で出る | ε = 1e-6, 1e-9: **全部**。ε = 1e-3: **98% 以上** |
| C2 | 境界の単位の係数が ε によらない（基準は ε = 1e-9、相対のずれの最大。始まりの時点で決まっていたかどうかが ε で食い違う単位があれば満たさない） | ε = 1e-3: 2% 以下。ε = 1e-6: 0.01% 以下 |
| C3 | 境界でない単位は、ε を入れても選ばれる式（減衰・周期）が変わらない | 変わる割合が ε = 1e-3: 2% 以下。ε = 1e-6, 1e-9: 0.5% 以下 |
| C4 | 対照: (a) ε = 0 に差し替えた格子が、今のコードの格子と、ここで使う x のすべてで一致する (b) 同じ入力で 2 回走らせた結果が一致する | 両方。満たさなければ**ほかの結果を読まない**（結果を書き出さずに止まる） |
| C5 | 合成の答え合わせ: (a) 減衰しない波の系列（`undamped_*` 600 本）が境界の単位になる割合 (b) 境界になったものを ε = 1e-6 で当てたとき、振幅（τ·e^係数）の真の振幅（2 × 値の幅を 5 にそろえた倍率）からの相対のずれの最大 (c) 減衰する波の系列（`damped_*`）で、境界でないものが選ばれる式を変えない割合（C3 と同じ基準値） | (a) 90% 以上 (b) 5% 以下 (c) C3 と同じ |

- 窓の集合（N ごと）で、境界の単位が 20 未満なら C1・C2 は、境界でない単位が 20 未満なら C3 は、**判定不能**（小さな数では判断しない）
- C1〜C3 は N = 12, 24, 48 のそれぞれで判定する。N = 24 だけ満たして他が外れれば、そう書く
- 基準値の置き方: 野球の値（下の参考）に余裕を持たせた値で、これ以上は結果を見ずに決めた。実データの結果を見て変えない
- 読み方: 判定できた基準をすべて満たしても**「矛盾する材料はなかった」までしか書かない**（「確かめられた」とは書かない）。満たさない基準があれば、どの基準が、どの集合で、どれだけ外れたかをそのまま書く。外れた単位は個別に見るが、基準は後から動かさない

### 参考（基準ではない）

野球（2013〜2026年、168 単位）: 境界の単位 24（約 14.3%）。係数（ε = 1e-6）の範囲 0.0774〜1.7637。ε = 1e-3 のときだけ選ばれる式が変わった単位が 1（2024年ソフトバンク。仕組みは特定できていない）。1e-6 と 1e-9 は 0。係数のずれ（ε = 1e-3 と 1e-9）の最大は約 0.7%、（1e-6 と 1e-9）は約 7×10^-6。

`τ`・窓の長さ・合成の系列の種類は、野球を離れるために置いた任意の選び方で、これが正しいという根拠はない。基準に関わるのは τ = 0.5 の主な集合だけ。

## 事後の確認（登録した基準の外）

`posthoc_boundary_forms.py` は、結果を見たあとに足したもの。境界の単位のうち、ε=1e-3 / 1e-6 で選ばれる周期が ε=1e-9 のときと違う単位を数え、その単位で 2 つの周期の式の誤差の2乗和を並べる。境界でない単位のうち ε=1e-3 / 1e-6 で選ばれる式が今のコードと違う単位についても、今のコードの式・減衰しない波・ε の波の誤差の2乗和を並べる。周期ごとの境界の単位の数を野球の 24 単位と並べる。基準にはしない。結果は `results/posthoc_boundary_forms.md`。

`posthoc_eps_ladder.py` は、第 3 回の結果を見たあとに足したもの。ε を 1e-4〜1/100 の固定の梯子で動かし、C2 の基準（登録した値と、第 3 回で延ばした値）を超える境界の単位と、ε の波が残らない単位を数え、動いた単位の周期・係数を梯子の上で並べる。基準にはしない。結果は `results-random/*/posthoc_eps_ladder.md`。テストは `tests/test_epsilon_generality_ladder.py`。

`eps_range_profile.py` は、第 3 回の結果を見たあとに足したもの。「そのデータで、ε がどこまで動かなかったか」を記録するためのもので、**ε の範囲や定数を決めるものではない**（範囲の既定値も置いていない）。境界の単位の係数が基準の ε=1e-9 と相対 10% / 1% / 0.1% / 0.01% 以内に収まった割合と、境界でない単位で選ばれる式が変わらなかった割合を、16 点の ε（1/100〜1e-13）で数え、すべて収まっていた最大の ε と、乱数の選び方（`draw_coefficients`）で ε がその値以下になる確率を並べる。別のデータには別の数字が出る（出てよい）ので、データごとに同じ表を作って並べて見るためのスクリプト。基準にはしない。別のデータには `--csv`（縦持ち）、`--prefix`（変数名の頭）、`--cadence`（month か day）を渡す。範囲を指定するときは `--eps-range MODE LO HI`（`eps_generality.py` と同じ書き方。MODE は inside / above / below）を付ける。LO と HI を格子に足し、その側の格子の ε について、許容ごとの最悪の収まった割合などをまとめる（`--random-eps K` と `--coef-seed` で、その側から ε を乱数で K 個選んで格子に足せる）。付けなければ出力は変わらない。結果は `results-random/*/eps_range_profile.md`。テストは `tests/test_epsilon_generality_range.py`。

## 乱数の ε と倍率の確認（第 3 回）: 事前登録

**走らせる前に書く。結果を見て、範囲・個数・種・基準値の置き方を変えない。** 第 1 回（主食価格）・第 2 回（物理量）で試した ε は 1e-3, 1e-6, 1e-9、倍率は 1e-6, 1e-3, 1, 1e3, 1e6 で、どちらも 1×10^(3 の倍数) だった。これは人間の都合で選んだ並びで、たまたま効く（効かない）値に当たっているかを見分けられない。そこで、決め打ちの値は残したまま（比べるため）、**ε = A×10^-N の A と N を乱数で選んだ値**を足して、同じ基準で試せるようにする。

この節は 2 版目。最初の版（A は小数 1 桁の 1.1〜9.9、N = 4〜8、倍率の e = -8〜0。コミット 2dfb881・4ac42c3）は、定義の見直しを受けて置き換えた。見直しの内容は次の 3 点で、最初の版の結果は `results-random/` を上書きして残さない（PR の履歴には残る）。

- A は有効数字 3 桁（1.00〜9.99）にする。1.0 や 1 桁は人間の都合の値で、3 桁のうち取れない値があった
- N は 3 から許す。N の上限は置かない（ε が十分小さければ ε→0 の側に収束するだけで、どこかで区切る理由がない）
- ε の条件は **0 < ε ≤ 1/100 だけ**。ゼロに限りなく近いがゼロではない、という以外に、値の形は決めない。float でそのまま与えてもよい（A×10^-N は乱数で選ぶときの作り方）。A×10^-3 は A ≥ 1.00 なら 1/1000 以上になるので、N = 3 から許す

### 足すもの

- `eps_generality.py` に `--random-eps K`（ε を K 個足す）、`--random-scales K`（倍率を K 個足す。報告だけ）、`--coef-seed 整数|auto`（省略は `SEED`。`auto` は実行ごとに変わり、選ばれた種と値は結果の `random_coefficients` に書く）。付けなければ出力は足す前とバイト単位で同じ（第 1・2 回の 9 ファイルを走らせ直して確かめる）
- 選び方（`draw_coefficients`）: ε = A×10^-N の **A = 1.00〜9.99**（百分の一の整数 100〜999 を一様に選んで 100 で割る。1.00 も 9.99 も選ばれうる）、**N = 3 から**。N は 3 に、「次の段へ進む」を確率 5/6 で繰り返した回数を足したもの（各段で確率 1/6 で止まる幾何分布。平均 N = 8）。一様には選べない（上限がない）ので、ε が大きく式が動きうる側に多く当たる形にした。N の上限は置かない。実装上は、A の 3 桁を保ったまま float で表せる N = 307 で止める（装置の限界で、N = 308 以降は 1.00×10^-308 が 3 桁を保てない）。この限界に当たる確率は (5/6)^304 で、0 とみなせる
- 倍率 = A×10^e の A は同じ。**e は 0 から、符号をランダムに、同じ幾何分布の回数だけ離す**（0 の両側、上限なし）。実装上は |e| ≤ 150 で止める（装置の限界。y の 2 乗の和が float の範囲を超えるのは |e| が 153 付近から）
- 重複なし。決め打ちの ε・倍率（1e-3, 1e-6, 1e-9 と `SCALES`）と同じ値は選ばない。決め打ちの ε・倍率はそのまま残す。基準の ε（C2 の比べる相手）は 1e-9 のまま
- 「係数」は第 1・2 回と同じ（落ち着く位置 × ε = ln(振幅/τ)）。ε を A×10^-N と書けば、位置 = (係数 / A) × 10^N。係数は ε によらない量なので、ε が違っても基準の ε（1e-9）と比べられる
- C1 の「ε の波が残った」は、落ち着く位置が有限であることも条件にする（ε が極端に小さいと、位置 = ln(振幅/τ) / ε が float の範囲を超えうる。超えたものは残ったに数えない）

### 基準

C1〜C4 は第 1・2 回と同じ判定（窓の集合ごと、判定不能の規則も同じ）を、決め打ちの ε と乱数の ε の**すべて**に当てる。登録した基準値は 1e-3, 1e-6（C3 は 1e-9 も）にしかないので、乱数の ε の基準値は、**登録した 2 点を log10(ε) でつないだ直線**とする（`threshold()`）。1e-3 より大きい側（1/100 まで）は同じ直線を**延ばす**。定義域は 0 < ε ≤ 1/100（これを外れる値は止まる）。float ならどんな値でも通る。

| 基準 | 1e-3 の値 | 1e-6 の値 | 1e-6 < ε ≤ 1/100 | ε ≦ 1e-6 |
|---|---|---|---|---|
| C1（ε の波が残る割合、以上） | 0.98 | 1.0 | 割合を log10(ε) の直線でつなぐ（1e-3 より上は延長） | 1.0 |
| C2（係数のずれ、以下） | 0.02 | 1e-4 | 値の対数を log10(ε) の直線でつなぐ（幾何補間・延長） | 1e-4 |
| C3（境界でない単位で式が変わる割合、以下） | 0.02 | 0.005 | 同上 | 0.005 |

直線の位置を f = (log10(ε) + 6) / 3 とおくと、1e-6 で 0、1e-3 で 1、1/100 で 4/3。C1 = 1.0 + (0.98 − 1.0) f、C2 = 1e-4 × 200^f、C3 = 0.005 × 4^f。

- 例（この種の ε）: 2.22×10^-3 は C1 0.9777 以上・C2 3.69% 以下・C3 2.35% 以下、1.76×10^-3 は C1 0.9784 以上・C2 3.09% 以下・C3 2.24% 以下、3.54×10^-4 は C1 0.9830 以上・C2 0.90% 以下・C3 1.62% 以下、7.82×10^-5 は C1 0.9874 以上・C2 0.283% 以下・C3 1.20% 以下、6.60×10^-6 は C1 0.9945 以上・C2 0.0425% 以下・C3 0.73% 以下、9.82×10^-9 以下の 4 つは 1e-6 の値（C1 全部・C2 0.01% 以下・C3 0.5% 以下）。1/100 ちょうどは C1 0.9733 以上・C2 11.7% 以下・C3 3.17% 以下
- つなぎ方は、基準値を結果を見ずに置くための約束で、これが正しいという根拠はない。ε が大きいほど許す幅を広げる向きは、第 1・2 回の 2 点（1e-3 のほうが緩い）に合わせた。1e-3 より大きい側の延長も同じ約束で、最初の版の結果を見ているが、延長の式は登録した 2 点の直線をそのまま延ばしただけで、その結果から調整していない。1/100 に近いほど基準が緩くなる（C2 は 11.7% まで）ので、そこで通ることの意味は小さい。読み方で補う
- C5（合成の系列。主食価格の回だけ）の C3 に当たる部分にも、乱数の ε を同じ基準値で当てる。物理量の回で合成を省くのは第 2 回と同じ
- 倍率は報告だけで基準はない（第 2 回と同じ）。読み方も第 1・2 回と同じ: すべて満たしても**「矛盾する材料はなかった」まで**。満たさない基準があれば、どの ε が、どの集合で、どれだけ外れたかをそのまま書き、外れた単位は登録した基準の外で別に見る。基準は後から動かさない

### 範囲を指定して選ぶ（結果を見たあとに足した。登録した値は変えない）

- `eps_generality.py` に `--eps-range MODE LO HI` と `--scale-range MODE LO HI` を足した。範囲は [LO, HI]、MODE は **inside**（LO 以上 HI 以下。両端を含む）、**above**（HI より大きい）、**below**（LO より小さい）。この 3 つは、重なりも抜けもなく分ける。LO と HI は `2.22e-3` でも `2.22×10^-3`（`x` でも可）でも書ける。LO ≤ HI で、ε は HI ≤ 1/100。`--random-eps K`（ε の範囲）、`--random-scales K`（倍率の範囲）と一緒に使う。範囲の既定値は置かない（毎回書く）
- 選び方: 範囲に入る (A, 指数) の組だけから、上の「選び方」で各指数が選ばれる確率を、範囲の中で比べ直して選ぶ（範囲を決めずに選んで、外れたものを捨てるのと同じ分布。範囲が狭くても選べる）。A は 100〜999 から一様。範囲の端が A の刻み（3 桁）に合っていなくてもよい。決め打ちの値と同じ値と重複は選ばない。範囲に入る値が K 個に足りなければ止まる
- ε は N = 3〜307 の範囲でしか選べないので、above は N = 3 の側（HI より大きく 9.99×10^-3 まで）、below は N = 307（1.00×10^-307）までで、それより外に出る範囲は空になって止まる。例として LO = 8.14×10^-13、HI = 2.22×10^-3 のとき、規則で選ぶと内側 70.0%、上 14.4%、下 15.6%（データによらない）
