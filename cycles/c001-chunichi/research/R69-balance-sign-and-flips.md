# R69: 9通りのます目で収支の符号は効くか・勝ち方が収支をひっくり返した単位（研究計画）

記録: 2026-10-06。計算を始める前に書いた。スクリプト [r69_flips.py](r69_flips.py) は書いたが、まだ実行していない。R68 で「得点 B × 失点 A」のます目の中の収支の符号だけは見ている（4/5 と 1/10）。ほかの8つのます目では見ていない。

## 位置づけ（R68 の種、ユーザーが承諾）

1. R68 の「ます目の中では収支の符号で A・B がほぼ決まる」は、1つのます目で結果を見てから足した読み。**9つのます目すべてで**、収支の符号がどれだけ A・B を分けるかを見る
2. 収支の符号と A・B が食い違った単位（**勝ち方が収支をひっくり返した単位**）の一覧を作る。R54 の巨人 2017・2018年、阪神 2015年、R68 の阪神・中日 2019年がこの形のはず

範囲は 2013〜2025年（2020年を除く、144単位）。ます目は R67 と同じ（`rf_adv`・`ra_adv` の2本線）。

## 読み方（先に決める。記述で、判定はしない）

1. ます目ごとに、収支 > 0 の単位の A の割合と、収支 ≤ 0 の単位の A の割合を並べる。「収支 > 0 なら A、≤ 0 なら B」が当たった単位の数を、ます目ごとと全体で書く
2. 収支の符号で読み違えた単位（収支 > 0 で B、収支 ≤ 0 で A）を、点の差より勝った数（`wins_vs_pythag`）・1点差・組み合わせ方と並べて列挙する。読み違えた単位のうち、勝ち方の向き（収支 > 0 で B なら負け越し、≤ 0 で A なら勝ち越し）が合っている単位の数を書く
3. 読み違えた単位のうち、中日の年と阪神の年を書く。リーグの線（越えるべき高さ `lg_bar`）にどれだけ近かったか（勝率 − バー）も並べる

全体で「収支 > 0 ⇒ A」が何割当たるかを、点の差で見込む勝率の 3.5位の線（R66 で 0.86）と並べる。

## 結果（2026-10-06、`r69_flips.py` を実行。`season.jsonl` は既存のまま、npb.jp へのリクエストは 0）

### 1. ます目ごとの収支の符号

| ます目（得点 × 失点） | 収支 > 0 → A | 収支 ≤ 0 → A | 収支の符号の当たり |
|---|---|---|---|
| A × A | 14/15 | — | 14/15 |
| A × AB | 12/17 | — | 12/17 |
| A × B | 6/6 | 0/9 | **15/15** |
| AB × A | 14/16 | 1/2 | 15/18 |
| AB × AB | 5/6 | 7/10 | **8/16** |
| AB × B | 1/1 | 5/14 | 10/15 |
| B × A | 4/5 | 1/10 | 13/15 |
| B × AB | — | 0/15 | 15/15 |
| B × B | — | 2/18 | 16/18 |

- 全体で収支の符号が当たったのは **118/144（0.82）**。点の差で見込む勝率の 3.5位の線（0.86）より少し低い
- R68 の読み（得点 B × 失点 A のます目では収支の符号でほぼ分かれる）は、**片側が強く片側が弱います目（A × B・B × A）ではそのとおり**（15/15・13/15）
- **得点 AB × 失点 AB（両方真ん中）では、収支の符号は分けない（8/16）**。収支 ≤ 0 でも 7/10 が A。真ん中どうしの組は、点の差ではなく別のもので A・B が決まる

### 2. 勝ち方が収支をひっくり返した単位（26）

- 収支 ≤ 0 なのに A: **16単位**。ロッテが5回（2013・2015・2016・2023・2024年）、阪神が3回（2014・2015・2019年）、DeNA が3回（2016・2019・2022年）、西武・巨人・日本ハム・広島・オリックスが1回ずつ
- 収支 > 0 なのに B: **10単位**。ソフトバンク 2013・2021年、広島 2015・2022年、西武 2015年、巨人 2017・2023年、**中日 2019年**、ロッテ 2019年、楽天 2022年
- 26単位すべてで、点の差より勝った数の向きが読み違いと合う（26/26）。勝率 = 点の差の分 + 勝ち方の分なので、これは算術で当然の向き。読みどころは「どの単位で起きたか」
- ほとんどが線の近く（勝率 − 越えるべき高さが ±.06 以内）。接戦の年に起きている
- **中日は、収支 ≤ 0 から勝ち方で A に入ったことが13年間で一度もない**。逆向き（収支 > 0 で B）は 2019年の1回。阪神は勝ち方で A に入った年が3回、ロッテは5回

## 読み

- 収支の符号は、片側が強く片側が弱います目ではほぼ A・B を決め、両方が真ん中のます目では決めない
- 勝ち方で収支をひっくり返して A に入ることは、特定の球団（ロッテ・阪神・DeNA）に偏って起きている。中日には一度もない。R55 の「中日の B の2つ目の道（勝ち方で落とした）」と合わせると、中日は勝ち方で拾う側に回ったことがなく、落とす側に回ったことがある

## 種

1. **勝ち方で拾う力は球団に付いているか**: ロッテ・阪神・DeNA の「収支 ≤ 0 で A」が偶然の範囲か。点の差より勝った数の年をまたぐ続き方（R1 の `alloc_z_next` と同じ考え方）を球団ごとに見る
2. 得点 AB × 失点 AB のます目（16単位）で A・B を分けるもの。R56 の越えるべき高さ、R62 の最後の区間を並べる
