# 補足パッケージの確認と未確認事項の更新

2026-10-03、ユーザー経由で `aoi_supplement_share.zip` を受領。36ファイル（MANIFEST自身を含む）。新しいネットワーク取得を行わず、`verify_supplement.py` で提供ファイル間と既存データの対応を確認した。記録は [supplement_validation.json](outputs/supplement_validation.json)。

## 今回確認できたこと

| 項目 | 結果 |
| --- | --- |
| MANIFESTのハッシュ・サイズ・ファイル網羅性 | 35ファイル全一致（MANIFEST自身は対象外） |
| イニングCSV | 前回の共有CSVとSHA-256まで同一。64項目の集計値は変更不要 |
| 全URLの採否 | 12,606 = 採用11,875 + 除外731。重複・重なり・未分類なし |
| 規定試合数による切り出しの再計算 | 採用11,875、ポストシーズン除外234。全て両チームで採否一致 |
| 同梱解析済みJSONとイニングCSV | 採用全11,875試合の回別配列・得点合計が一致 |
| 2013–25年の対戦カード数 | 822カードすべて規定の試合数と一致 |
| 共有されたN回戦番号 | 11,028試合すべて、既存データから再計算したカード内の消化順と一致 |
| 公式戦とポストシーズンが同日のケース | 2013-10-12/13、2018-10-13、2020-11-14の4日で整合 |
| イニング合計不一致460件 | 中止389＋ノーゲーム71で全件説明。ノーゲーム全72件のうち残り1件は合計一致 |
| 数値付きxの補足表 | 961回すべて、採用試合の最終実施回・得点・打撃側へ結合可能 |

今回のチーム別切り出しは正しく機能していた。以前の「日付だけの一律切断では不十分」という注意は、Grok側の実装が誤っていたという意味にはしない。各チームの公式戦がそのチームのポストシーズンより前に完了するという前提を使った方式であり、他球団が同日に公式戦を行うこととは両立する。さらに今回、既存カレンダーデータとの試合集合一致、カード数、消化順による裏付けが得られた。

こちらの既存取得で使った大会見出しはカレンダー一覧側の情報で、Grokが説明する個別試合ページのタイトルとは別の情報源。旧BISの個別タイトルが「公式戦」でも、双方の説明が矛盾するわけではない。

## x付き回の情報が利用可能になった

提供分類と分類ルールを照合すると、walkoffが914回、incomplete_otherが47回。2013–2025年の主集計範囲に含まれるのは合計885回で、残り76回は2026年。全961回を13年分として扱わない。

`data/observations/r001_inning_features/partial_inning_annotations.csv` にURL・球団・回番号・得点・提供分類を保持し、既存の試合単位派生データに対応付けられるようにした。公開する年度・球団別の件数は [partial_innings_by_year.csv](outputs/partial_innings_by_year.csv)。

この情報で「途中終了フラグが共有されていない」という前回の不足は補われた。元のイニングCSVにフラグがないという仕様自体は変わらない。64項目は従来どおり、数字のある途中終了回も実施1回として数える。今回フラグを理由に得点を落としたり、回数を分数に換算したりしていない。得点圏・打席数・アウト数は引き続き不明。

47回のincomplete_otherは共有コードの分類名である。コードは数値付きxのうち「ホーム・9回以降・ホーム勝利」に該当しないものをこの群に入れている。個々のコールド・中断理由をこちらで原HTMLから独立特定したものではない。

## 再現性の改善と残る範囲

前回不足していたgamelist.py、games_raw.json、team_games.csvなどが今回同梱されたため、解析済みデータ以降の来歴を追えるようになった。共有スクリプトはGrok側の絶対パスと外部ライブラリを前提にする。こちらではその環境を偽装せず、標準ライブラリによる別スクリプトで照合した。

N回戦番号・x文字列は提供者がHTMLから抽出した観測であり、生HTMLそのものは今回も未受領。ここで確認したのは抽出値と他データとの整合性であり、全ページをこちらで再読したという意味ではない。また、打撃回配列の一致は同じ取得工程に由来する二つの表現の一致でもあり、完全に独立した二つの観測とは呼ばない。

```sh
python research/gpt-r001-score-allocation/verify_supplement.py --share /path/to/aoi_supplement_share
```

実データでexit=0。欠落ファイルは66、入力不整合は65。元ファイルを変更せず、提供パッケージのMANIFESTと確認コードのハッシュを出力に保持する。
