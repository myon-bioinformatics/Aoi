# 波の減衰 0 → ε の感度: 実データでの結果（探索・暫定）

`../wave_eps_sensitivity.py` を実データで走らせた結果です。確定済みの出力（`outputs/season.jsonl` など）は変更していません。**ε の値は暫定の置き場所で、結論には使いません。扱いは今後決めます。** 試合データそのものはコミットしていません（`wave_*` の派生値と集計だけ）。

入力の出どころと照合は、同じ階層の `../wave_eps_trial_results/README.md` と同じです（[PR #127](https://github.com/myon-bioinformatics/Aoi/pull/127) の `games_raw.json` から 2013〜2025 年の公式戦 11,028 試合を取り出したローカルの表）。

## 置いたファイル

- `wave_eps_sensitivity.md` / `.json`: ε の格子（0.1〜1e-12 の 9 通り）と、線の始まり・終わりを動かした 8 通りの結果
- `wave_eps_boundary_membership.jsonl`: 基準の境界の 23 単位が、動かした 8 本の線のうち何本で境界に残るか
- `wave_eps_settle_coefficients.md` / `.json`: 落ち着く位置を「係数 × 10^n」（ε = a × 10^-n）で書いたときの、ε ごとの位置・単位ごとの係数・最小の ε の係数で言い当てたときの外れ（`../wave_eps_settle_coefficients.py` を `../wave_eps_trial_results/wave_eps_rows_*.jsonl` に走らせたもの）
- `wave_eps_sensitivity_gate.json`: 対照の関門（ε なしの実行 vs 確定済み `season.jsonl`）。156 単位、違う行 0、pass

## 結果（要点）

- 基準の線（10 試合から・シーズン最後まで、sims = 200）では、ε なしで減衰 0 の単位は 156 のうち 23。ε ≤ 0.01 では、線の最後の値は約 0.87ε、収束先は約 0.94ε 動き、落ち着く位置は「係数 × 10^n」の形になる（ε = a × 10^-n。ε を 10 倍小さくすると指数 n が 1 上がり、係数は動かない。係数は決めた数ではなく行から出てきた数で、a = 1 の行では 0.077〜1.764、a を替えれば 1/a 倍。ε = 1e-3・1e-6・1e-9 の行で、最小の ε の係数から言い当てた位置の外れは絶対で最大 0.64（シーズン 1 つぶんが 1）、相対で最大 0.7%。`wave_eps_settle_coefficients.md`）。振れ幅が最初から 0.5 順位以下の 5 単位は、落ち着く位置が ε によらず一定。
- ε = 0.1 で起きること: 2019 年の西武が ε の波に乗り換え（収束先の動きは 0.11 順位）、2024 年の広島は当てはめの周期が 2 → 1 に替わって収束先が 1.75 順位動く（rmse 0.862 → 0.865）。この 2 点は手元での確認で、確認に使ったスクリプトは置いていない。なお（落ち着く位置 − 始まり）× ε の中央値が ε = 0.1 で 0.780 に上がる（小さい ε では 0.7316 のまま）のは、「係数 × 10^n」の形からの外れ（絶対で最大 0.64、ε によらない上乗せ）に ε を掛けた分で、比例が崩れたのではない。
- 2024 年のソフトバンクは順位がずっと 1.0 の平らな線（rmse 0）で、ε = 0.03・0.001・1e-12 のときだけ ε の波が選ばれる（0.01・0.003・1e-4〜1e-9 では選ばれない）。ε = 0.001 の保存行（`../wave_eps_trial_results/wave_eps_rows_0.001.jsonl`）では、減衰 0.5・周期 1/3 → 減衰 0.001・周期 1/4 に替わるが、`wave_limit_rank` と `wave_settle_x` は変わらない。**入れ替わりの仕組みは特定できていない**（当てはめ候補どうしの誤差が 1e-14 前後の丸めの差しかない、という見立ては仮説で、単独の再現では入れ替わりを再現できなかった）。
- 線の始まり・終わりを動かすと、境界の単位は大きく入れ替わる（開始 5・20・30 試合で基準の 23 単位との重なり 0.27〜0.31。終わりを順位確定日にすると、10 試合からの線では 0.84）。8 本の線のすべてで境界に残るのは 2015 オリックス、2017 楽天、2021 DeNA、2022 西武の 4 単位だけ。残った単位でも収束先は中央値 0〜0.34・最大 1.5〜2.3 順位動き（10 試合・順位確定日だけは最大 0.095）、ε による動き（ε ≤ 1e-3 で最大 0.0009）とは桁が違う。

## 注意

- 実データは NPB 2013〜2025 の 1 組だけで、減衰 0 の単位は 23 と少ない。
- 最初の試験（`../wave_eps_trial_results/`）は Aoi の main にある sakanalytics、この感度は #124 の枝にある版で走らせた。どちらも対照の関門を通り、ε = 1e-6 で結果は一致する。
