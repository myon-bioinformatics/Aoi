# USB / flash storage — USD per MB (hblok)

- **Panel:** `usb_flash_hblok_panel.csv`
- **What:** Historical flash/USB retail price observations in USD/MB (and unit cost/size).
- **Source:** https://hblok.net/storage_data/flash.csv (McCallum / jcmit lineage).
- **Coverage:** 2003–2017; global USD retail (mostly NewEgg); `is_usb=1` flags USB sticks (~74 of 96 rows).
- **License / terms:** Public data page; cite hblok.net / original compilers.
- **Caveats:** **Not multi-country** — one global USD retail series. Capacity and product mix shift over time. Ends 2017 in this file. No FX fills.
- **Retrieved:** 2026-10-25 (Asia/Tokyo box).
