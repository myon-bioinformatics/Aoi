## 要点

- **乱数の ε に当てた基準は、主食価格 100 件、物理量の月次 90 件、日次 90 件のすべてを満たしました。** 判定不能はなく、対照（C4）も 3 つとも通りました。「矛盾する材料はなかった」までしか言えません
- 決め打ちの ε（1e-3, 1e-6, 1e-9）と合成の系列（C5）の判定は、第 1・2 回の結果と**そのまま同じ**でした（乱数の ε を足しても動かないことの確認）。主食価格で外れた 1 件（ε=1e-3、12 か月の窓、C2 のずれ 0.577）も、第 1 回のままです
- **係数のずれは ε にほぼ比例します。** 最大のずれ ÷ ε は、集合（入力 × 窓の長さ）ごとにほぼ一定で（乱数の 10 個の最小〜最大の差は 6% 以内）、決め打ちの ε=1e-6 の値とも同じでした（下の表 2）。ε が 2.0×10^-8 から 6.7×10^-4 まで変わっても、同じ線の上です。第 1 回で 1e-3 だけ外れた 1 窓は、この線の外にあった例外で、乱数の ε の中で 1e-3 に最も近い 6.7×10^-4 では出ませんでした。ただし 4.4×10^-4〜6.7×10^-4 の 3 個だけなので、外れが出始める ε は特定していません
- 境界でない単位で選ばれる式が変わったのは、主食価格の 12 か月の窓で ε=6.7×10^-4 と 6.6×10^-4 のときの 1 単位ずつ（非境界 2,844 単位のうち。基準は 1.8% 以下）。第 1 回の ε=1e-3 でも同じ窓の長さで 1 単位でした。4.4×10^-4 以下では 0 です。同じ単位かどうかは見ていません
- **値の単位を変えたとき**（報告だけ）: 主食価格でも物理量と同じ向きでした（表 3）。倍率 1.8×10^-4 以上では何も動かず、1.6×10^-8 と 8.6×10^-8 では選ばれる式が 9 割以上（主食価格 2,104 / 2,192、月次 207 / 221、日次 470 / 478）、決め打ちの 1e-6 では約半分（1,056 / 2,192、115 / 221、272 / 478）が動きました。乱数の倍率の組は 1e-7〜1.8×10^-4 に 1 つも入らず、動き始める境目は今回の組では見えません。主食価格でも同じ仕組み（`EPS_WAVE_TIE` の絶対値）かは、事後の確認をしていません

## 野球に寄っていた点・領域によらない点（第 2 回からの更新）

- 3 刻みの決め打ちに隠れていた ε の問題は、今回の乱数の範囲（2.0×10^-8〜6.7×10^-4）では見つかりませんでした。係数のずれが ε に比例することと、基準の範囲に収まることは、主食価格・物理量の月次・日次で共通です
- y 方向の絶対値の許容に結びつく倍率の動きは、物理量に限らず主食価格にもありました。値の幅を 5 にそろえてから当てはめるこのハーネスの外（別の幅のまま `sakanalytics` に渡す場合）で起きます。直し方は決めていません

## 限界

- 乱数の ε・倍率は 1 つの種の 10 個ずつ。別の種で同じになるとは言えません。ε の範囲は N = 4〜8 で、1e-3 より大きい ε と 1e-9 より小さい ε は見ていません。個数が少なく、1e-6 より大きい ε（補間した基準値を使うもの）に当たったのは 6 個（N = 4 が 3 個、N = 5 が 3 個、N = 6 は 0 個）、倍率は 1e-7〜1.8×10^-4 に 0 個です
- 乱数の ε の基準値は補間で置いた約束で、登録した基準そのものではありません。実際のずれは基準値に余裕を残しています（C2 のずれは、どの集合でも基準値の 0.45 倍以下）。基準値の置き方が判定を決めたわけではありません
- 窓は独立ではなく、物理量は大気・気候の測定に偏る（第 1・2 回の限界のまま）。合成の系列は主食価格の回だけ
- 倍率の動きの理由は、物理量の月次・日次で事後に確かめたもの（第 2 回）で、主食価格では確かめていません
