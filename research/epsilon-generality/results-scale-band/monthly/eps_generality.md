## 乱数で選んだ ε と倍率

種 20261027。ε = A×10^-N（A = 1.00〜9.99、N = 3 から上限なし）と倍率 = A×10^e（A は同じ、e は 0 から両側へ上限なし）の A と指数を乱数で選び、決め打ちの値に足した。ε の条件は 0 < ε ≤ 1/100 だけ。乱数の ε の基準値は、登録した 1e-3 と 1e-6 の基準値を log10(ε) でつないだ直線（1e-3 より大きい側は延長、1e-6 以下は 1e-6 の値）。

- ε: なし
- 倍率: 9.57×10^-5, 5.98×10^-5, 3.16×10^-5, 8.91×10^-6, 5.00×10^-6, 1.92×10^-6, 9.50×10^-7, 8.63×10^-7, 7.66×10^-7, 1.03×10^-7
- 倍率を選んだ範囲: inside（1.00×10^-7 〜 1.00×10^-4。inside は両端を含み、above は HI より大きく、below は LO より小さい）
