# Numbeo clothing / utilities / markets — crowd-sourced country snapshot

- **Panel:** `numbeo_clothing_utilities_markets_crowd_panel.csv`
- **What:** Country-level USD prices from Numbeo cost-of-living rankings: jeans, summer dress, Nike shoes, men's leather shoes, basic utilities (85 m²), apples, potatoes, rice, bottled water, gasoline.
- **Source:** Numbeo `country_price_rankings` HTML geochart (`itemId` pages).
- **Raw:** `/workspace/aoi-phase2/raw/specific_products_2026-10-25/numbeo/`
- **Coverage:** ~102 countries; **single cross-section** (snapshot); 10 items; 1020 rows.
- **Crowd-sourced:** **Yes** — label clearly in any use.
- **Caveats:** User-contributed; not official NSO. Underwear/toothpaste not in Numbeo COL catalogue (SKIP). Some itemIds 429-throttled (chicken/bananas etc. not fetched).
- **Retrieved:** 2026-10-25 (Asia/Tokyo).
