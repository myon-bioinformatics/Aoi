# Part6受領：持続する特徴と因果の境界

2026-10-04、ユーザー提供の `aoi_part6.zip`（14ファイル）を受領。Part5の照合済み球団年CSVとPart4の共有イニングCSVを使い、提供コード `p6.py`、`p6b.py`、`p6c.py` を隔離した作業コピーで順に再実行した。10個のCSVは全行・全列が一致した（数値は相対許容差1e-10、絶対許容差1e-12）。Python 3.12.14、NumPy 2.3.5、pandas 2.2.3で実施。新しい原HTML観測でも、元のイニング配置を独立に確認する検査でもない。

元の提供レポートとコードは変更していない。本記録は、再現できた観察、追加した感度確認、採用しない解釈を分ける。数値の一致は因果命題の成立を保証しない。

## 再現できた観察

- 得点回当たり得点（RPS）の隣接年相関は全144ペアで0.185908、2020を含むペアを除いた120ペアで0.193676。
- 中日はRPSがリーグ下位2の年が13年中12年、2017–2025年は9年連続。他球団の最長連続は2年。下位2から翌年も下位2の遷移は中日10/11、他球団8/37。
- 2013–2025年をまとめた中日のRPSはホーム1.661830、ビジター1.669137で、両主催区分とも12球団中最低。これは年別平均ではなく、各区分の総得点÷総得点回数。
- 勝率回帰の標準化係数は攻撃SRが0.537611、攻撃RPSが0.199634。比は約2.69。
- 下位2→Bクラスの条件付き率はSR39/52=.750、RPS40/52=.769。連続値での回帰と二値の順位区分は異なる問い。
- Part4のリーグ平均との差とPart5の反例7件との差は比較基準が異なる。55%と68%はそれぞれ対数差の構成であり、原因や改善効果の配分ではない。

## 追加確認：中日を除くと相関はほぼ0

| 対象 | 全年ペア n / r | 2020を含むペア除外 n / r |
| --- | --- | --- |
| 全12球団 | 144 / 0.185908 | 120 / 0.193676 |
| 中日以外 | 132 / −0.020917 | 110 / 0.019168 |

同じ球団の隣接年を結合し、2019→2020と2020→2021を除外する。2019→2021を隣接年として補わない。中日の継続的な低さはプールした相関にも影響する。この結果は「全球団に共通する持続法則」よりも「この期間の中日に特徴的な持続」を支持する記述である。プールした相関は球団間の平均差と球団内変動を分離していない。中日を先に選んだ探索であり、独立した追試や将来予測の検証ではない。

## 回帰と不確実性の扱い

同じ156球団年、目的変数W/(W+L)、切片＋攻守SR/RPSの4列という提供モデルを維持して感度確認した。攻撃SR−RPSの係数差は0.146602。

| 標準誤差の扱い | SE | 係数差 / SE |
| --- | --- | --- |
| 通常OLS（独立・等分散） | 0.073209 | 2.002517 |
| 球団単位のCR1、12群 | 0.079891 | 1.835012 |
| 年度単位のCR1、13群 | 0.104199 | 1.406932 |

CR1はサンドイッチ分散に `m/(m−1) × (n−1)/(n−p)` を掛けた単一のクラスタ補正。球団と年度を別々に確認したもので、両方の依存を同時に処理したものではない。群数も少なく、リーグ内の相対化・順位制約・対戦による依存が残る。較正済みp値や有意/非有意の最終判定を追加しない。

相関のFisher-z区間と通常OLSのSEも、独立標本の仮定に依存する。年ペアは球団年を共有し、同じ球団の年次値も繰り返す。提供値の再現と、不確実性の仮定が妥当であることは別問題である。独立ベルヌーイ試行と仮定した10/11の二項確率は、その仮想モデルの参考値であり、異常性を検定した確率ではない。

得失点差/試合への高いR²は、説明変数が得点・失点の分解成分であることとも機械的に結び付く。回帰はイニング/試合の項、球場、相手等を統制していない。「同じ総得点ならSRで稼ぐ方が勝ちに変換される」という機序や、1点の価値の同等性を直接検証したモデルではない。

## 解釈の採否

| 提供報告の解釈 | 本研究での扱い |
| --- | --- |
| 残差の持続が低いので13年間は運では説明できない | 採用しない。ピタゴラス残差は運の直接測定ではなく、低い隣接年相関から累積的な影響も排除できない。 |
| 中日のRPSは構造的な原因 | 長期に持続する攻撃上の特徴・原因候補として保持。継続の確認と因果の確認を分ける。 |
| SRはRPSの約2.7倍の効果 | この標本・モデル内の標準化係数の比。介入・改善効果ではない。P-Bが一般則として成立したとは判定しない。 |
| ビジターでも低いので球場だけでは説明できない | 本拠地主催試合だけに限られない低さは確認。ただし主催区分は実球場ではなく、相手球場・対戦相手・年度等の調整前に球場要因を排除しない。 |
| SRは地力、RPSは大量点・采配を表す | 追加観測を要する仮説。総得点と得点回数だけでは長打・四球・走者・采配へ帰属できない。 |

採用する要約は「この期間の中日では、得点回当たり得点の低さが長く持続した。なぜ持続したか、順位やCS出場へどれだけ因果的に寄与したかは未解明」。2012年・2026年は今回の比較対象外、2020年のAクラスとセのCS非開催は区別する。
