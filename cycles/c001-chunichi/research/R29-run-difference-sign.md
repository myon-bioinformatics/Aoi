# R29: 片側だけ上位のチームは、得失点差の符号で分かれるか（研究計画）

記録: 2026-10-05。計算を始める前に書いた。R28 の結果と、その記述（失点だけ上位で得点5・6位の26単位）は見ている。P122 の範囲の得失点差と順位の組、P123 の範囲のうち得点4位の17単位は見ていない。

## 位置づけ

- R27: A クラスなら、得点か失点の一方は3位以内（P115 の対偶）
- R28: 片側だけ上位のチームは A と B がほぼ半々。失点だけ上位で得点5・6位の26単位では、A の6単位はどれも失点1・2位で、得失点差プラスが5単位。同じ側で得失点差プラスなのに B は中日 2019年だけ

「片側だけ上位なら、得失点差の符号が分ける」は、得失点差プラス ⇒ A（P1、全体 0.84）を、片側だけ上位の範囲に絞った形になる。全体で言えることが、片側だけ上位でもそのまま言えるか、どちらの側でも同じかを見る。

## 読み方（先に決める）

1. **P122 と P123（きっかけ以外）**: 両方が支持なら、片側だけ上位のチームは**得失点差の符号で分かれる**（一般の形）。片方だけ支持なら、その側だけで言う
2. **逆（A なら得失点差プラス）**: 逆が支持なら、片側だけ上位のチームが A に入るには、得失点差をプラスにすることがほぼ必要。逆の判例（得失点差マイナスで A）は、点の差より多く勝った年として `wins_vs_pythag` を並べる
3. **中日**: 中日の片側だけ上位の単位が、得失点差の符号でどちらに入るかを数える（記述）。中日の B が「マイナスだから B」で説明できるなら、中日の問いは「なぜ得失点差がプラスにならなかったか」（得点の不足）に戻る
4. P121 は判定を記録するだけで、読みは 2026年の確かめ（R18 の手順）を待つ
