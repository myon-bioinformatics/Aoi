# R36: 中日 2019年は、同じ形で A に入ったチームと何が違ったか（研究計画）

記録: 2026-10-05。計算を始める前に書いた。スクリプト [r36_case.py](r36_case.py) は書いたが、まだ実行していない。

## 位置づけ

R35 で、得点がはっきり足りず失点ははっきり上回る形（誤差の幅で得点 −1・失点 +1）は、中日以外で11単位、そのうち A が5（阪神 2013・2019、ソフトバンク 2012・2019、西武 2022）だった。中日 2019年はこの形で、得失点差もプラス（+19）なのに5位。ユーザーの依頼で、2019年を同じ形のチームと並べ、理由を探す。

見ているもの: 中日 2019年の `wins_vs_pythag`（−4.71）、阪神 2019年の `wins_vs_pythag`（+3.7）、R12〜R17 の 2019年の読み（強い相手から点が取れない P76、強い相手との試合全体の点が少ない P80）。ほかの指標の11単位の値は見ていない。

## 方法

1対5の事例の比べなので、命題の判定ではなく**記述**にする。並べる指標を先に決める（スクリプトの `MEASURES`）。

| まとまり | 指標 |
|---|---|
| 点の差を勝ちに変えたか | `wins_vs_pythag`、`one_run_net`、`blowout_net`、`alloc_z_strat` |
| 相手の強さ別 | `vs_top_wpct`、`vs_lower_wpct`、`opp_conv_top/mid/low`、`opp_net_gap_top_c`、`opp_env_gap_top_c` |
| シーズンの流れ・並び | `course_wpct_diff`、`series_lost_pct` |

## 読み方（先に決める）

1. 中日 2019年が、**A の5単位の範囲（最小〜最大）の外**にある指標を「2019年の差」とする
2. そのうち、**A の5単位と中日以外の B の6単位が重ならない**指標は、この形のチーム一般の A・B の分かれ目の候補。新しい id で命題にし、2026年で確かめる（見た後の命題なので、同じデータでは確かめにならない）
3. 2019年の差が A と B で重なる指標なら、**2019年に寄った差**として記録するだけにする
4. 2019年がどの指標でも A の範囲の内側なら、「同じ形の A と区別できる指標は、ここにはない」と書く

## 限界

- 事例は1つ、比べる相手は5つ。差は「並べたら外れていた」以上の意味を持たない
- 13の指標を並べるので、どれかが偶然外れることはありうる（13個のうち1〜2個が外れても、それだけでは何も言わない）
