# R22: シーズンの中の線に、山（極大）と谷（極小）はあるか（研究計画）

記録: 2026-10-04。計算を始める前に書いた。`traj_*` はこの計画のために作った列で、実データではまだ計算していない。
ただし、中日の順位の動き（R20 の 1/4・1/2・3/4・最終の表）は見ている。

## 位置づけ（ユーザーの見立て）

- 中日のシーズンの終わりは、ほぼ毎年 4〜6位。始まりが 2〜4位だったとして、上がっていく・横ばいを保つ時期があったのなら、日付ごとの順位の線はカクカクする。でもカクカクは横軸の単位（日ごと）の問題で、折れ線であること自体に意味はない
- そこで、線をあえてなめらかな式（3次・4次・5次の式、または波）で表してみる。すると、ある時点から **f'(x) < 0**（下がり始める）になっていて、他のチームはその頃 **f'(x) > 0** だった、というところがあるかもしれない。**極大と極小が現れているか**をまず見る
- もし波（sin・cos）で近似できるなら、その波の幅を超えられず、周期がある。上がる時期があっても、最後は 4〜6位のどこかに落ち着く線なのかもしれない

## 方法

### 線と式

| 線 | 値 | 読み方 |
|---|---|---|
| 順位の高さ | リーグの球団数 + 1 − 順位（6球団なら 1位 = 6、6位 = 1） | 上がれば正。f'(x) < 0 は順位を下げている時期 |
| 貯金 | 勝 − 敗 | f'(x) はその時期の勝ち越しのペース。f'(x) < 0 は負け越している時期 |

- 横軸は日付。そのリーグの最初の試合の日を 0、最後の試合の日を 1 とする
- 開幕直後の数試合の順位は揺れが大きすぎるので、**リーグの全球団が10試合に届いた日から**最後の日まで、試合のあった日ごとの値を使う
- その範囲に **3次式** y = c0 + c1·x + c2·x² + c3·x³ を最小二乗で当てる。3次式は山と谷を1つずつまで持てる、いちばん簡単な式（係数が計算しやすい）。f'(x) = c1 + 2c2·x + 3c3·x² の根が範囲の内側にあれば、f'' の符号で山（極大）か谷（極小）かを決める
- 列: 形（`rise`・`fall`・`peak`・`valley`・`peak-valley`・`valley-peak`）、山があるか・その位置、谷があるか、最後の日の傾き f'(1)

### 基準: 力が一定でも山や谷はできる

勝ち負けが毎試合ランダムに決まるだけでも、順位や貯金の線はふらつき、3次式を当てれば山や谷ができる。だから**山や谷があること自体は、何かがあった証拠にならない**。

そこで、その年の各チームの力を一定（その年の勝率）として、実際の日程のまま、引き分けでない試合の勝敗を両チームの勝率の Log5 で引き直したシーズンを 200回作り、同じ線の引き方で山・谷ができる割合を数える（`*_peak_base`・`*_valley_base`。乱数の種は年で固定）。実際の山・谷の数を、この割合を独立な確率とした見込み（ポアソン二項分布、R10 と同じ）と比べる（`outputs/trajectory_expectation.jsonl`）。

## 命題

| 命題 | 範囲 | ならば | 強さ |
|---|---|---|---|
| P97 | 中日の B クラスの年 | 順位の高さの線に山がある（上がってから下がる） | 半分より多く |
| P98 | 中日以外の B クラス | 同上 | 半分より多く |
| P99 | 中日 | 貯金の線に山がある（貯金を増やしてから減らす） | 半分より多く |
| P100 | 中日の B クラスの年 | 最後の日の順位の高さの傾きが負（下がりながら終わる） | 概ね |
| P101 | 中日以外の B クラス | 同上 | 概ね |

どの命題も、成り立つかどうかより、**基準（力が一定）と比べてどうか**で読む。

## 読み方（先に決める）

1. **山・谷があるか**（ユーザーの最初の問い）: 単位ごとに数え、`trajectory_expectation.jsonl` で基準と比べる
   - 群（全体・A クラス・B クラス・中日・中日の B クラス）ごとに、観測した山（谷）の数が見込みより多く、P(見込み以上) < 0.05 なら、**力が一定のときのふらつきを超えた山（谷）がある**。シーズンの途中で力が変わった（上がってから下がった）跡と読む
   - 見込みより少なく、P(見込み以下) < 0.05 なら、線は力が一定のときより**まっすぐ**（山も谷も少ない）
   - どちらでもなければ、山・谷は**力が一定のときのふらつきの範囲**で、形から何かを読むことはしない
2. **中日に特有か**: P97 と P98、P100 と P101 の率の差が 0.2 以上なら中日に寄った形。0.2 未満なら B クラスに共通の形
3. **下がり始める位置**: 中日の山の位置（x）を年ごとに並べる（記述）。同じ年の A クラスのチームの線と並べる
4. **波の見立て**: 3次式は山と谷を1つずつまでしか持てない。1で山・谷が基準のふらつきの範囲なら、波（周期と幅）を当てても、ふらつき以上のものは読めないと考える。1で基準を超えたら、次に波の式を当てる

## 限界

- 順位はほかのチームの成績で動く。順位の高さの線は自分の力だけでは決まらないので、自分の力の線として貯金の線も並べる
- 3次式は山と谷を1つずつまでしか表せない。何度も上下する線は、ならされて見えなくなる
- 基準は「その年の勝率で一定」。シーズン途中のけが・補強・日程の偏りのような変化は、基準からのずれとして出る（ずれを「不運」とは呼ばない）
- 2020年は他の年と同じく計算するが、統計からは除く
