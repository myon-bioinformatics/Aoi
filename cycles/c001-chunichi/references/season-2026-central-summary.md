# 2026年セ・リーグの年成績（年単位の感度探索用）

取得・転記確認日: 2026-10-15。以下のNPB公式ページはいずれも「全日程終了」と表示。

- [チーム勝敗表](https://npb.jp/bis/2026/stats/std_c.html): G/W/L/T、掲載順の順位
- [チーム打撃成績](https://npb.jp/bis/2026/stats/tmb_c.html): RF、H/AB/TB/BB/HBP/SF
- [チーム投手成績](https://npb.jp/bis/2026/stats/tmp_c.html): RA（自責点ではなく失点）、G/W/Lの相互照合

数値を確認して `season-2026-central-summary.jsonl` に転記した。
丸め済みの出塁率・長打率を再利用せず、保存した `batting_counts` から以下を計算した。

- `bat_obp = (H+BB+HBP)/(AB+BB+HBP+SF)`
- `bat_iso = (TB-H)/AB`
- `bat_d_* = 自分の値 − 同年セの他5球団の単純平均`
- `upper_half = rank <= 3`。CS出場そのものとは区別する。

これは感度探索に必要な年成績だけの補助入力であり、通常の試合取得・測定パイプラインの2026年分を実行したものではない。
既存 `outputs/season.jsonl` やR18確認ファイルは変更していない。イニングの頻度・大きさなど、ここから導けない列は補わない。
同じ2026年データが通常の年表へ取り込まれた場合は、この補助入力を外す。重複したチーム×年を渡すとCLIはエラーにする。

2026年の順位・中日の成績はすでに会話やR18の記録で知られている。
今回の係数・閾値選択では2026を使わないが、完全な盲検や独立した新規発見の証拠とは呼ばない。
