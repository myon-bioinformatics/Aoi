# R20: 勝ち試合・負け試合の点と、シーズン後半の失速（研究計画）

記録: 2026-10-04。計算を始める前に書いた。`wl_*`・`course_*` はこの計画のために作った列で、実データではまだ計算していない（R12 の `half1_vs_pythag`・`half2_vs_pythag` は 3位・4位のチームについて見ている）。

## 位置づけ（ユーザーの見立て）

1. **負け試合なのに点が多い**（効率の悪い負け方）。負け試合の点が、平均の得点を高く見せているのかもしれない
2. **勝ち試合はロースコア**。接戦を制したとも言えるが、単に点が取れずに投手戦になっているだけかもしれない
3. **ロースコアの試合は制するが、ハイスコアになった途端に制せない**のかもしれない
4. それが投手に負担をかけ、**シーズン中盤以降に失速する**。序盤は2〜4位でも最後は6位、が毎年続くなら、長期戦が得意ではない
5. 投手の実力が高いことと、投手に負担を強いることが、**両方とも成り立っている**かもしれない（スコアに現れない危ない勝ち方）
6. 勝ち試合の得点を、「本来の見込み」（この得点の分布なら、勝つときは平均何点で勝つはずか）と比べる

## 測るもの

### 勝ち試合・負け試合（`wl_*`）

| 列 | 中身 |
|---|---|
| `wl_rf_win` / `wl_rf_loss` | 勝ち試合・負け試合の得点／試合（実際） |
| `wl_rf_win_exp` / `wl_rf_loss_exp` | 同じ量の見込み（6 の「本来の見込み」） |
| `wl_rf_win_gap` / `wl_rf_loss_gap` | 実際 − 見込み |
| `wl_wpct_low` / `wl_wpct_high` | 両チームの合計得点が、同じ年・同じリーグの試合の中央値以下／より多い試合の勝率 |
| `wl_wpct_low_gap` / `wl_wpct_high_gap` | 実際 − 見込み |

見込みは、同じチーム・同じ年の得点と失点を、**ホームどうし・ビジターどうしの中で組み合わせだけランダムにしたとき**の値（R1 の `alloc_*_strat` と同じ基準。球場の違いは組み合わせの中にとどまるので、係数は使わない）。点の数え上げで厳密に計算する。

例: 得点が {1, 5, 0, 2}、失点が {0, 4, 3, 6} の4試合なら、16通りの組のうち勝ちは5組で、勝つときの得点の見込みは 3.6点。実際の勝ち試合が 1点と5点（平均 3点）なら、見込みより 0.6点少ない。

**先に分かっていること（読み方に効く）**: この基準からのずれは、1つの試合の中で得点と失点が一緒に動く（両チームとも点が入りやすい試合・入りにくい試合がある）と生まれる。そのとき、勝ち試合の得点は見込みより少なく、負け試合の得点は見込みより多くなる。つまり**見立て1と見立て2は同じ量の表と裏になりやすい**（R17 の鏡の形を、1試合ずつの単位で見るものに近い）。また、この向きのずれは全球団に出うるので、中日の傾向かどうかは他球団と比べて読む。

### 前半と後半（`course_*`）

| 列 | 中身 |
|---|---|
| `course_wpct_h1` / `course_wpct_h2` / `course_wpct_diff` | 前半・後半の勝率と、後半 − 前半 |
| `course_rank_q1` / `course_rank_h1` / `course_rank_q3` | 試合数の 1/4・1/2・3/4 までの勝率での順位（順位の動きをたどる） |
| `course_fade` | 最終順位 − 前半の順位（正なら前半の位置より下で終わった） |
| `course_rf_d` / `course_ra_d` | 後半と前半の得点／試合・失点／試合の差の、他球団の平均との差（季節による点の入りやすさの変化を除く） |
| `course_ra_h1_d` | 前半の失点／試合の、他球団の平均との差 |
| `course_close_win_h1` / `_d` | 前半の勝ちのうち2点差以内の割合と、その他球団の平均との差 |

前半と後半は各チームの試合数で半分に切る（143試合なら前半71・後半72）。順位は各チームのその時点までの試合だけの勝率で並べたもので、ある日付の順位表とは少し違う。

## 読み方（先に決める）

- **P85〜P88（中日）**: 中日の13年のうちの年数と、他球団との比べの両方で読む。中日の傾向と言うのは、(a) 中日の年の多く（10年以上）がその向きで、かつ (b) 中日の13年の平均が12球団の中で端から2番目以内のとき。(a) だけなら全球団に共通の形で、中日の理由にはならない
- **P85 と P86** が両方成り立てば、上に書いたとおり同じ量の表と裏（1試合の中で得点と失点が一緒に動く）。片方だけなら、別の何かがある
- **P89 と P90**: 中日の B クラスの年のうち前半3位以内の割合が、他の B クラスのチームより **0.2 以上高ければ**、中日の B クラスは「前半は上位にいて後半に落ちる」形に寄っている。差が 0.2 未満なら、中日に特有の落ち方とは言わない
- **P91〜P94**:
  - P91 が成り立ち P93 が成り立たない → 前半の接戦の勝ちと後半の失点の増え方の結びつきは、前半の失点の少なさからの戻りだけでは説明できない。投手の負担と矛盾しない（起用の記録がないので、負担そのものは見られない）
  - P91 と P93 の両方 → 負担と戻りを、このデータでは分けられない
  - P92 と P94 の両方 → 後半の勝率の下がり方は、前半の勝ち方が後半に続かない（基準に戻る）ことでも説明できる
  - P91 が成り立たない → 前半の接戦の勝ちは、後半の失点の増え方と結びつかない
- 中日の順位の動き（1/4・1/2・3/4・最終）は、年ごとの表で記録する（判定ではなく記述）

## 見直す条件（反証）

- P88: 中日の後半の勝率が前半より低い年が13年中7年以下 → 「毎年後半に落ちる」とは言わない
- P89: 中日の B クラスの年のうち、前半3位以内が半数以下 → 「前半は上位にいた」は中日の B クラスの典型ではない
- P91・P92: lift が 1 に近い（Fisher の p ≥ 0.05）

## このデータでできないこと

- **打数を入れた試合ごとの見方**（勝ち試合の打数など）: 手持ちは試合ごとの最終スコアとシーズン合計の打撃成績だけで、試合ごとの打撃記録がない
- **投手の負担そのもの**（登板数・投球数・連投）: 投手の記録がない。前半の接戦の勝ちの割合で近づけるだけ
- **ある日付の順位表**: 各チームの試合数で切った勝率で並べる

## 限界

- 前半・後半は試合数で切るので、交流戦（5〜6月）はほぼ前半に入る
- 季節による点の入りやすさの変化は、他球団の平均を引いて除く（R16 と同じ考え方）
- 結果を見た後に命題を変えるときは、新しい id で言い直す
