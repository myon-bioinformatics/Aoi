# R18: 2026年での確かめ（手順の事前登録）

記録: 2026-10-04。2026年のデータを Aoi に取り込む前に書いた。2026年の公式戦はまだ全球団が終わっていない。

## 位置づけ

これまでの式（[FINDINGS.md](../FINDINGS.md) の式1〜4）は、どれも作るきっかけと同じデータ（2012〜2025年）で選んだ・見つけたもの。作るのに使っていない年で照らすのが確かめになる。2026年が最初のその年。

単位は12（6球団 × 2リーグ）しかないので、統計の判定はしない。**命題ごとに、2026年の単位を4つの欄に分けて数え、判例の単位は名前を出す**。読み方（何件なら何と読むか）はこの記録で先に決める。

## 確かめの前に、2026年について見たもの

確かめの値を見てから読み方を変えないために、すでに知っていることを書いておく。

| 見たもの | 出どころ | 中身 |
|---|---|---|
| 順位表（2026-10-02 時点） | npb.jp、WebFetch で1ページ | 各球団の試合数（138〜143）と勝率。A/B の別はこの時点で全球団決まっている: セ A 阪神・巨人・DeNA、B 広島・ヤクルト・中日。パ A ソフトバンク・西武・日本ハム、B オリックス・ロッテ・楽天 |
| 中日の数字 | Grok のコメント | 60勝81敗2分、ピタゴラスの見込みとの差 −8.4 |

- **後件の側（A クラスか B クラスか）は、全球団すでに知っている**。前件の側（得点・失点の分布、組み合わせ方、打撃、強い相手との試合）は、中日を除いてどの球団も見ていない
- **中日は前件の一部を間接的に知っている**。ピタゴラスの見込みとの差 −8.4 は得点と失点の比から出る値で、組み合わせ方（`alloc_z_strat`）に近い量。中日 2026 の P52 などは、確かめとして弱い単位として読む
- 命題は 2026年の値を見て作っていない。**P1〜P84 の定義は、この記録の後に変えない**。変えたくなったら新しい id で言い直し、2026年はその言い直しの「作るきっかけ」として扱う

## 手順

1. 2026年の公式戦を全球団が 143試合終えたことを、順位表（1ページ）で確かめる。終わる前には取り込まない（構造の確認 `--strict` が試合数の不足で止まる。止まるのが正しい）
2. [pipeline.toml](../pipeline.toml) の `years` を `2012-2026` にして実行する
   - npb.jp から取るのは 2026年のページだけ（月別カレンダー 9ページ、チーム打撃 2ページ）。取得済みの年は取り直さない
   - 2026年は進行中の年として扱われるので、2026年中は実行のたびに更新の有無だけを確かめる（変わっていなければ 304 で本文は来ない）
3. 自動で `outputs/confirmation.md` ができる（[analysis.toml](../analysis.toml) の `[confirm]`。2026年を取り込むまでは「データがまだない」とだけ書かれる）
   - 命題の範囲のうち**年の範囲だけを外し**、チーム・条件の範囲はそのまま使う（年の範囲は作ったときのデータの範囲なので）
   - 各単位を、成立（前件も後件も当たる）／判例（前件に当たるのに後件に当たらない。元の命題と対偶の判例）／逆の判例（前件に当たらないのに後件に当たる。逆と裏の判例）／どちらも当たらない、のどれかに置く。値が空なら判定不能
   - `detail` に挙げた命題は、単位ごとの状態も並べる
4. 結果をこの記録に書き足す

期待値は、学習データ（2012〜2025年、2020年を除く156単位）での率をそのまま 2026年の12単位に当てたもの。2026年は A・B が6単位ずつ。

## 2026年を足した後の、ふだんの判定

`years` を 2012-2026 にすると、年の範囲を持たない命題のふだんの判定（`outputs/index.md`、台帳）にも 2026年が入る。これは**確かめではなく、単位が増えたことによる判定の更新**として記録する（11年すべてで成り立っても単位が少なく判断保留だった命題は、判定が進むことがある）。確かめは `confirmation.md` の 2026年の単位だけ。

## 限界

- 単位が12しかない。期待値どおりでも「確かめられた」とは書かず、「学習データと矛盾しない」と書く
- 後件（A/B）を先に知っている。前件を見ていないので命題の定義には影響しないが、判例が出た単位の読み方を後から作りやすい。判例の単位は、まず問いとして記録する
- 中日の単位は前件の一部を見ている
- イニング単位の命題（P22〜P30、P33〜P35、P38、P39、P44、P48、P62、P63）は、2026年のイニング単位のデータがない限り判定不能
