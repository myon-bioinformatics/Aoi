## 乱数で選んだ ε と倍率

種 18750922。ε = A×10^-N（A = 1.00〜9.99、N = 3 から上限なし）と倍率 = A×10^e（A は同じ、e は 0 から両側へ上限なし）の A と指数を乱数で選び、決め打ちの値に足した。ε の条件は 0 < ε ≤ 1/100 だけ。乱数の ε の基準値は、登録した 1e-3 と 1e-6 の基準値を log10(ε) でつないだ直線（1e-3 より大きい側は延長、1e-6 以下は 1e-6 の値）。
