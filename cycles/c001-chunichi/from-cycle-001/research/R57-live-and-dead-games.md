# R57: A・B に効く試合と、決まった後の試合を分ける（研究計画）

記録: 2026-10-05。計算を始める前に書いた。列（`rank_fixed_*`・`live_*`・`dead_*`）はテストを通して push した（01b6732）。実データでの値は、Actions で `season.jsonl` を作り直すまで見ていない。

## 位置づけ（ユーザーの見立て）

- CS の出場チームや4〜6位が決まった後の試合は、そのチームにとって A・B に効かない。それなのに、すべての試合を同じ重みで評価している。これが誤差や、分析がうまくいかない原因の1つかもしれない
- 後から振り返って、日付ごとに各チームの順位（1〜6）がどれかに確定していく様子を出す。**意味のある試合群と、もう決まってしまって意味のない試合群を整理する**
- そのうえで、有効な試合での勝率・負け率、有効な勝利が何をきっかけに得られたかを見る。1勝が、補正すると実は1ではなかった可能性もある
- さらに先: ある1〜4日（ランダムや連続）の試合結果を入れ替えたときに、順位表や差がどう変わるかを見る（R58 以降）
- 以前の R26（決まるまでのデータだけで足りるのでは、というユーザーの見立て）の続き

## 列（どれも控えめな日付。直接対決を考えないので、実際より遅く出ることはあっても早くは出ない）

| 列 | 中身 |
|---|---|
| `rank_fixed_x` / `rank_fixed_left` / `rank_fixed` | 最終順位（1〜6）が数の上で確かになった日の位置・残り試合・順位。最後まで同率なら空 |
| `live_g` / `live_wpct` / `live_rd_g` | 自分の A・B が決まった日まで（その日を含む）の試合。決まらなければ全試合 |
| `dead_g` / `dead_wpct` / `dead_rd_g` | 決まった日より後の試合 |

## 読み方（先に決める。記述で、判定はしない）

範囲: 2020年を除く全単位。

1. **効かない試合の量**: `dead_g` の分布（中央値・最大）と、A・B 別の中央値。中日の B 12年それぞれの `dead_g` と、B が確定した日（`clinch_out_x`）
2. **最終順位の確定**: `rank_fixed_x` の中央値を順位（1〜6）ごとに並べる。中日の B の年の順位が確定した日
3. **決まった後に勝ち方が変わるか**: 効かない試合がある単位で、`dead_wpct − live_wpct` と `dead_rd_g − live_rd_g` の中央値を、A が確定したチームと B が確定したチームに分けて並べる。中日の B の年も並べる
4. **効く試合だけで見ると、中日の位置は変わるか**: 効く試合だけの勝率（`live_wpct`）で、中日の B 12年が R53 の帯（全試合の勝率で引いた .486〜.514）のどこにいるかを数える。帯そのものを効く試合で引き直すことはここではしない（次の計画）
5. 効かない試合が多い単位（`dead_g` の上位）を列挙する。基準の値は決めず、多い順に並べるだけ

ここで分かったことを、R58（数日分の結果を入れ替えたときの順位表の変わり方）の計画に使う。

### 3. 決まった後に勝ち方が変わるか

| 決まった側 | 単位 | 勝率の差（後 − 前）の中央値 | 点の差/試合の差の中央値 | 後のほうが勝率が高い |
|---|---|---|---|---|
| A が確定 | 73 | **−.041** | −0.47 | 25/73 |
| B が確定 | 71 | **+.045** | +0.47 | 44/71 |
| 中日の B | 12 | +.076 | +0.47 | 7/12 |

- **決まった後の試合では、A のチームは勝率が下がり、B のチームは上がる**。どちらも .500 の方向に寄る。点の差でも同じ向き
- 効かない試合は、全試合の勝率を .500 の方向に少し押し、A と B の差を少し縮める。ユーザーの見立て（効かない試合を同じ重みで数えると、評価がずれる）と同じ向き
- ただし、これが「決まって力を抜いた・選手を入れ替えた」ためか、「決まった時点が上振れ・下振れの山だったので戻った」（平均への回帰）ためかは、この記述では分けられない。B が確定するのは負けが込んだ直後なので、戻りが入りやすい

### 4. 効く試合だけで見ると、中日の位置は変わるか

- 中日の B 12年の効く試合だけの勝率は .387〜.482 で、**12年とも帯（.486〜.514）の下**。全試合の勝率より下がった年が 6（効かない試合で勝ち越していた 2013・2014・2022・2023・2024・2025年）、上がった年が 4（2015〜2018年、最大 +.015）、ほぼ同じが 2（2019・2021年）
- 効かない試合を外しても、中日の帯との距離は大きく変わらない（6年は少し遠く、4年は少し近く）

### 5. 効かない試合が多い単位

1位の独走（ソフトバンク 2015年: 前 .678 → 後 .500、巨人 2013年: .635 → .500、ソフトバンク 2014年: .613 → .263）と、早く沈んだ6位（ロッテ 2017年: .345 → .591、西武 2024年: .322 → .500、日本ハム 2017年: .387 → .632）が上位を占める。独走した1位の全試合の勝率は、効かない試合で低く出ている。

## 読み

- 効かない試合は1単位あたり平均で数試合と少なく、**中日の B 12年の結論（帯の下）は変わらない**
- 一方で、効かない試合は .500 の方向に寄るはっきりした傾向がある（A −.041、B +.045）。独走した1位や早く沈んだ6位では 20試合を超え、リーグ全体の形（`lg_lead_gap`・`lg_line`・帯の端）に効きうる
- 1勝の重みを補正する見立ては、まず「効かない試合を外したときに、リーグの形と帯がどう動くか」で試せる

## 種（次の計画へ）

1. **効く試合だけの帯**: `live_wpct` で帯（A の最低・B の最高、1年抜き）を引き直し、帯の端（巨人 2017・2018年）が動くか。効く試合の範囲はチームごとに違うので、比べ方を先に決める
2. **R58（ユーザーの見立て）**: 数日分（1〜4日、ランダムや連続）の試合結果を入れ替えて、順位表と差がどう変わるか。効く試合の中の日と、効かない試合の日で、入れ替えの効き方が違うかを見る
3. 「戻り」と「力を抜いた」を分ける: 確定していないが同じくらい上振れ・下振れした時点（同じ勝率の山）と比べる
