## 読み方の注意

- 減衰を ε にしても、当てはめの波そのもの（L・B・周期）は連続に動く。戻るのは「収束する先」と「落ち着く位置」の定義で、減衰がごく小さいので落ち着く位置は非常に大きい（1 を超える = シーズン中には決まらない）値になる。
- 戻った wave_limit_rank は、減衰しない波では**波の中心**という形式的な値で、「収束する先」という意味ではない。`eps_used` で分けて読む。
- wave_settle_pct が変わるのは、確定済みで settle_x が空欄だった単位（自分が無限大だったもの）。疑似シーズン側でも減衰 0 が選ばれると、以前は無限大どうしの同順位（0.5 と数える）だったものが、ε では有限の大きな値どうしの比較になり、並びが付く。
- 線が完全に平らな単位では、どの式も誤差の2乗和がほぼ 0 になり、選ばれる式が丸め誤差と固定の許容値（1e-12）で決まる。その場合は ε に差し替えると選ばれる式が変わりうる（暗黙の許容値 = 前回の洗い出しの (C)）。
- `eps_used` = 選ばれた式の減衰が ε そのもの。出力の行に付けている。
