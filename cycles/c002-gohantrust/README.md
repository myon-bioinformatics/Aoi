# サイクル2: GohanTrust（米価と指標の組み合わせ）

青いプロジェクト第2弾。複数の指標を一つの式に組み込み、小さな標本で厳しい規律のもとに「ある項や形が米価を予測するか」を確かめる。サイクル1（[中日ドラゴンズ](../c001-chunichi/README.md)）と同じく、結論を急がず、判断できないものは判断できないと記録する。

## 練習式

GohanTrust は架空の練習式。実データで検証する手順を作るために置いている。

```text
P = K · q · (100 − A) · E
```

- P: 米の価格（円）。q = 5 kg（5kg あたりの価格として扱う）
- A: 青木率（内閣支持率 + 与党第一党支持率）
- E: エンゲル係数
- K: 係数（P から逆算する）

形の候補は `primary` (100−A)、`alt200` (200−A)、`exp_neg` exp(−βA)、`aoff` (A を使わない P ∝ q·E)、`prop_A`（符号を逆にした形）。A ≥ 100 では `primary` が成り立たない（2013年の年平均 A = 100.87）。

言い方の規則: 差が検出できないときは「判断保留（検出できず）」と書き、「効かない」「通らなかった」とは書かない。政治に関する因果の物語は書かず、定義だけを注に置く。

## 進め方

1. 事前宣言を書いて固定する（時刻とハッシュを記録）
2. 再現ゲート: 既知の結果を同じ手順で再現できるか確かめる。合わなければ本番を走らせない
3. 実行し、別実装で検算する
4. 報告を書く。結果を見て出た着想は「未検討」に置くだけで、その場では走らせない

## 既知の欠け

- 入力の P（米価）と E（エンゲル係数）は、Grok の報告書に載った値を転記したもの。元のパネル CSV はこのリポジトリにない。2016〜2022年の P は報告書の表で整数に丸められている
- 転記値は `research/staple-price-survey/` の日本の系列と照合した（`tests/test_c002_lag1.py`）。**一致した範囲**: E の 2005〜2023年は家計調査（二人以上の世帯、e-Stat）、P の 2005〜2015年は小売物価統計調査の 5kg 月次（e-Stat）の年平均
- **照合できていない範囲**: P の 2016〜2025年、E の 2024〜2025年（e-Stat の系列が #118 では P は 2015年、E は 2023年まで）。同じ表にある FPMA の東京 5kg 系列は別の系列で、P はその 0.81〜0.93 倍の水準で、前年比の差も −0.03〜+0.05 ある。2015年と2016年のあいだで系列が切り替わっているかどうかは、確認できていない
- 青木率 A を含む形（`primary` など）の結果と、窓の延長（2005年以降）の結果も Grok の報告書によるもので、原本はこのリポジトリにない。L1 は A を使わない
- 国際比較のデータは [`research/staple-price-survey/`](../../research/staple-price-survey/)（データのみ）にある。L1 の入力の照合にだけ使い、検証には使っていない
