# サイクル1: 中日ドラゴンズ

GENESIS.md の「Note On Evidence」で予告した、問いを生んだ観測の再構築。

## 最終ゴール

**中日ドラゴンズは、なぜ14年間 CS に進出できなかったのか。** その答えを出すこと。

命題の判定・異議・作り直しは、すべてこの問いに向かうための手段として行う。

**本題は「なぜ B クラス（4〜6位）が続いたのか」、つまり1〜3位になれなかった理由**（ユーザーの判断、2026-10-04）。CS の有無で例外を作るより、B クラスで定義する。2020年はこれまでどおり除外の例外として扱う。

**いまの到達点は [FINDINGS.md](FINDINGS.md)**（式・結果・弱めた見方・開いた問い）。全命題の最新の判定は [`outputs/index.md`](outputs/index.md)（自動生成）。

数え方の注意（結論を書くときに、どれで言っているかを必ず明示する）:

- CS 進出の条件は、6球団リーグでは3位以内。判定で使う `upper_half`（上位半分）と一致する
- 「14年間」は 2013〜2026年を指す（2012年は2位で進出）
- 2026年の CS 不出場は確定している（npb.jp の順位表、2026-10-02 時点: 中日 59勝81敗2分・残り1試合で最大 .4255、3位 DeNA は残り2試合を全敗しても .493）。最終順位（4〜6位のどれか）はまだ決まっていない。取得範囲（`pipeline.toml` の `years`）はシーズン終了後に 2012〜2026 に広げる
- 2020年は CS が開催されず、中日は3位。数え方で結果が変わる。下の値は外部レポート（`references/`）のもの。2026年の B クラス・CS 不出場は確定済み。実データで確かめる

| 数え方 | 結果 |
|---|---|
| 厳密な B クラス（2020年の3位は A クラス） | 14年中13年が B |
| 2020年を除く | 13シーズン連続 B |
| CS に出場していない | 14年連続（注） |

（注）2020年は CS が開催されていない。CS が開催された年に限れば、厳密には13年連続（2013〜2019、2021〜2026）。「14年連続」は、2013〜2026年の14シーズンで一度も CS に出場していない、という意味で使う。

## 問い

- 観測: 中日ドラゴンズは長いあいだ、セ・リーグの下位に位置するシーズンが続いた（**取得したデータで数え直す**。記憶では書かない）
- 問い: 既存の指標（得失点・ピタゴラス期待勝率）は、この結果を十分に説明しているか
- 順位: 偏りがなければ、各シーズンの順位の期待値は1〜6のどれも同じはず。下位（4〜6位）がどれだけ続いているかを観測する。CS の有無は扱わない（リーグによって制度が異なり、後からできた制度でもあるため）

## 実行

```bash
python nagoyaction/nagoyaction.py doctor cycles/c001-chunichi/pipeline.toml
python nagoyaction/nagoyaction.py run    cycles/c001-chunichi/pipeline.toml --receipt data/receipts/c001.jsonl
```

GitHub 上では Actions の「cycle c001 (chunichi)」で実行する（main に入るまでは `run/c001` ブランチへの push で起動。結果はそのブランチにコミットされる）。中身は同じコマンド。
取得はカレンダー約126ページ＋打撃成績28ページ（3秒間隔）で、取得済みのページは取り直さない（Actions のキャッシュ。止まった実行でも保存する）。
