## 観察：複数の回で得点する試合が少ない

2013–2025年、全実施回・攻撃・home/away合算の球団年単純平均。比較先は中日を除くセ5球団であり、Part4の「セ全体」とは異なる。

| 指標 | 中日 | 他セ5球団 |
| --- | --- | --- |
| 無得点の試合 | 11.13% | 8.91% |
| 得点した回が1回の試合 | 26.61% | 23.99% |
| 得点した回が2回以上の試合 | 62.26% | 67.10% |
| 得点した回が3回以上の試合 | 31.58% | 37.85% |
| 試合内で6回以上連続無得点 | 36.88% | 33.14% |
| 2回以上連続得点した試合 | 28.48% | 33.15% |
| 得点試合での最大得点回のシェア | 66.35% | 64.84% |
| 得点試合の回別得点HHI | 0.610 | 0.586 |

2回以上得点した試合の割合は13年中12年で他セ5球団平均を下回る。一方、6回以上連続無得点の割合が上回るのは10年、HHIが上回るのは9年で、全ての年に同じ特徴があるわけではない。

双方が6回まで攻撃した11,008試合に限定し、各試合の1–6回だけを使うと、2回以上得点した割合は中日40.06%、他セ46.07%。差の方向は同じ。これは9回裏未実施・延長の影響を小さくした比較で、無条件の因果的補正ではない。

## 参照モデル：無得点試合の超過は特別大きくない

得点回の頻度が低ければ、連続無得点や得点の少数回への集中も機械的に増えうる。そこで各年・球団・home/away別の得点回数と実施回数を固定し、得点印を一様に配置する参照と比べた。

| 無得点試合率 | 中日 | 他セ5球団 |
| --- | --- | --- |
| 実測 | 11.130% | 8.910% |
| 配置モデルの期待値 | 10.872% | 8.646% |
| 実測−期待値 | +0.258ポイント | +0.263ポイント |

2020年除外でも超過は中日+0.255ポイント、他セ+0.243ポイント。中日の超過が他セ平均より大きいのは13年中5年。先頭6回だけでは超過は中日+0.577ポイント、他セ+0.951ポイント。

この参照に対して、中日の無得点試合が特別多く上乗せされているという傾向は見えない。得点が一部の試合に偏ることを、無得点試合の多さの主説明として採用する材料は今回の比較では乏しい。モデルが正しい、全て偶然、偏りが存在しないと結論したわけではない。相手・起用・回・試合状態による違いはこの配置モデルに含まれない。

## 検証・実行

6件の新規テストは、無得点と未定義値、8回攻撃の分母、試合をまたがない遷移、得点集中の区別、超幾何確率と全列挙の一致、重複・ミラー不一致・回欠落での停止を確認。既存研究テストを合わせ27件成功。その後、入力照合と全指標計算を実行してexit=0を確認した。exit=0は計算・整合性確認の成功であり、研究命題が真であるという意味ではない。

リポジトリのルートから、共有ZIPを展開したディレクトリを指定する。新スクリプトはPython標準ライブラリのみ使用する。

```sh
python -m unittest discover -s research/gpt-r001-score-allocation -p 'test_inning_features.py'
python research/gpt-r001-score-allocation/inning_features.py --share /path/to/aoi_inning_share
```

前提は既存の `data/observations/r001/games.jsonl`。欠落時は66、不正入力・照合不一致は65で停止する。元の共有CSVを変更せず、ハッシュを保存する。全研究テストには既存研究のrequirements.txtも必要。
