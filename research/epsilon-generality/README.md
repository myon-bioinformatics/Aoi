# ε の汎用性の確認: 野球以外の連続データで使えるか（探索・事前登録）

ε（波の減衰 0 を置き換える小さな値）の扱いは、ここまで中日・NPB の順位の線（`cycles/c001-chunichi/exploratory/wave_eps_*`）だけで見てきました。この文書は、**走らせる前に**、野球以外の連続データで ε が使えるかを何で判断するかを書いたものです。結果を見て基準を変えません。結果は `results/` に、この文書とは別に置きます。

ε の値は暫定の置き場所で、結論には使いません（ε は記号。値と扱いは今後決める）。

## 見ること・見ないこと

- 見る: `sakanalytics.wave_basis` の「減衰 0」の格子を ε に差し替える方法（`wave_eps_trial.make_wave_basis`）が、野球以外の連続データでも、(1) 差し替えた先が選ばれ、収束する先と落ち着く位置が有限の値で出る、(2) 落ち着く位置を「係数 × 10^n」（ε = 1 × 10^-n）と書いたときの係数が ε によらない、(3) 減衰 0 でない単位の結果を動かさない、か。
- 見ない: 野球の列（`wave_osc`、`wave_limit_rank_h1` など、順位・試合・季節に結びついた派生の列）。ε を別の場所で使うこと（`log(1+x)` を使う指標、θ = 0 や空欄の置き換え、青木率の端の ε）。これらは別に確かめる。
- ε の意味は x の単位で決まる: 位置 ≈ 係数 / ε なので、「ε = 1e-6」は「窓の長さの 10^6 倍先」を指す。ここでは x を窓の長さで [0, 1] にそろえるので、ε は窓の長さに対する値。別の x の単位で使うときは、どの長さに対する ε かを先に決める必要がある。

## 入力

### 実データ: 主食価格の月次の系列

`research/staple-price-survey/staple_survey_vertical.csv` の `staple_price:*` の行（61,157 行、5 つの出どころ: FAO FPMA、WFP の 2 つのファイル、米国 BLS、日本 e-Stat）。

- 系列 = (国, 変数, 単位, 出どころ, 注) の組。注には市場・価格の種類が入っているので、同じ月が 2 つの行にならない（なれば止まる）。通貨は出どころのまま（為替の換算はしない）
- 月 = 日付の年と月（日にちは無視する。WFP の年次ファイル由来の 5,029 行は 15 日の日付）
- 窓 = 月が途切れずに続く区間ごとに、先頭から N か月ずつ、**互いに重ならない**窓を並べる（余りは使わない）。N = 12, 24, 48。**主な窓は 24 か月**
- 窓の値の幅（最大 − 最小）が 0 の窓は使わない（数だけ記録する）
- 正規化: x を [0, 1]（窓の最初の月が 0、最後が 1）に、y を「最初の月が 0、幅が 5」にそろえる（`(v − v0) × 5 / (max − min)`）。幅 5 は野球の順位（1〜6 位）の幅

### 合成の系列（答えが分かっている）

各 200 本、24 点、x は [0, 1]。種類ごとの乱数は `random.Random(f"{SEED}/{id}/{i}")`（SEED = 20261026）。観測の雑音は N(0, 0.02)（`noise` だけ N(0, 1)）。波の位相は一様乱数。

| id | 式（v = ） | 答え |
|---|---|---|
| `undamped_p1`, `undamped_p0.5`, `undamped_p0.25` | 3 + 2·cos(2πx/P + φ)、P = 1, 0.5, 0.25 | 減衰 0、周期 P |
| `damped_l1`, `damped_l3`, `damped_l8` | 3 + 2·e^(−λx)·cos(2πx/0.5 + φ)、λ = 1, 3, 8 | 減衰 λ、周期 0.5 |
| `linear` | 3 + 2x | 参考のみ（基準なし） |
| `noise` | 3 + N(0, 1) | 参考のみ（基準なし） |

## 事前登録: 基準

「決まった」とみなす幅 τ は 0.5（値の幅 5 の 10%。野球の半順位と同じ大きさ）を主とし、0.25 と 1.0 も動かして記録する。ε は 1e-3, 1e-6, 1e-9。

用語: **境界の単位** = 今のコード（ε なし）が減衰 0 の式を選んだ単位。**係数** = 落ち着く位置 × ε（始まりの時点で決まっていた単位 = 位置が窓の最初と同じ単位は、係数なし）。

| 基準 | 内容 | 満たす条件 |
|---|---|---|
| C1 | 境界の単位で、ε を入れても ε の波が選ばれ、収束する先と落ち着く位置が有限で出る | ε = 1e-6, 1e-9: **全部**。ε = 1e-3: **98% 以上** |
| C2 | 境界の単位の係数が ε によらない（基準は ε = 1e-9、相対のずれの最大。始まりの時点で決まっていたかどうかが ε で食い違う単位があれば満たさない） | ε = 1e-3: 2% 以下。ε = 1e-6: 0.01% 以下 |
| C3 | 境界でない単位は、ε を入れても選ばれる式（減衰・周期）が変わらない | 変わる割合が ε = 1e-3: 2% 以下。ε = 1e-6, 1e-9: 0.5% 以下 |
| C4 | 対照: (a) ε = 0 に差し替えた格子が、今のコードの格子と、ここで使う x のすべてで一致する (b) 同じ入力で 2 回走らせた結果が一致する | 両方。満たさなければ**ほかの結果を読まない**（結果を書き出さずに止まる） |
| C5 | 合成の答え合わせ: (a) 減衰しない波の系列（`undamped_*` 600 本）が境界の単位になる割合 (b) 境界になったものを ε = 1e-6 で当てたとき、振幅（τ·e^係数）の真の振幅（2 × 値の幅を 5 にそろえた倍率）からの相対のずれの最大 (c) 減衰する波の系列（`damped_*`）で、境界でないものが選ばれる式を変えない割合（C3 と同じ基準値） | (a) 90% 以上 (b) 5% 以下 (c) C3 と同じ |

- 窓の集合（N ごと）で、境界の単位が 20 未満なら C1・C2 は、境界でない単位が 20 未満なら C3 は、**判定不能**（小さな数では判断しない）
- C1〜C3 は N = 12, 24, 48 のそれぞれで判定する。N = 24 だけ満たして他が外れれば、そう書く
- 基準値の置き方: 野球の値（下の参考）に余裕を持たせた値で、これ以上は結果を見ずに決めた。実データの結果を見て変えない
- 読み方: 判定できた基準をすべて満たしても**「矛盾する材料はなかった」までしか書かない**（「確かめられた」とは書かない）。満たさない基準があれば、どの基準が、どの集合で、どれだけ外れたかをそのまま書く。外れた単位は個別に見るが、基準は後から動かさない

### 参考（基準ではない）

野球（2013〜2026年、168 単位）: 境界の単位 24（約 14.3%）。係数（ε = 1e-6）の範囲 0.0774〜1.7637。ε = 1e-3 のときだけ選ばれる式が変わった単位が 1（2024年ソフトバンク。仕組みは特定できていない）。1e-6 と 1e-9 は 0。係数のずれ（ε = 1e-3 と 1e-9）の最大は約 0.7%、（1e-6 と 1e-9）は約 7×10^-6。

`τ`・窓の長さ・合成の系列の種類は、野球を離れるために置いた任意の選び方で、これが正しいという根拠はない。基準に関わるのは τ = 0.5 の主な集合だけ。

## 野球に結びついている部分（コードを読んで挙げたもの。このハーネスでの扱い）

| 部分 | 野球での意味 | このハーネスでの扱い |
|---|---|---|
| `WAVE_SETTLE = 0.5` | 半順位（6 球団なので順位の幅は 5） | 値の幅を 5 にそろえ、τ を変数として 3 通り動かす。式の選び方は τ によらない（誤差の2乗和だけで決まる）はずなので、それも確かめる |
| `WAVE_PERIODS`・`WAVE_DECAYS` | シーズンの何割で 1 周するか、1 シーズンあたりの減衰 | 窓の長さを 1 として同じ格子を使う（格子そのものは変えない） |
| 始まりの値 `h0` を当てはめで動かさない | 「全球団が決めた試合数に届いた日」の値は観測そのもの | そのまま使う。実データでは窓の最初の月の値が雑音を含みうる（合成の雑音で出る） |
| `EPS_WAVE_TIE = 1e-12`・`EPS_WAVE_SOLVE = 1e-12`（絶対値） | 値の幅が 5 前後の尺度 | 値の幅を 5 にそろえて使う。別の幅でそのまま使えるとは言えない |
| 線の始まり x0 > 0 | 試合数が決まった日からシーズンの最後まで（1 より短い） | 窓の最初を 0 とする。野球の落ち着く位置は x0 + ln(振幅/τ)/λ、ここは ln(振幅/τ)/λ |
| `wave_osc`・`wave_settle_pct`・`wave_osc_base`・前半だけの当てはめ（`_h1`）、イニング・打撃の列 | 順位の線の派生・命題の材料 | 使わない |

`sakanalytics` は変更しない（PR #24 は触らない）。

## 事後の確認（登録した基準の外）

`posthoc_boundary_forms.py` は、結果を見たあとに足したもの。境界の単位のうち、ε=1e-3 / 1e-6 で選ばれる周期が ε=1e-9 のときと違う単位を数え、その単位で 2 つの周期の式の誤差の2乗和を並べる。境界でない単位のうち ε=1e-3 / 1e-6 で選ばれる式が今のコードと違う単位についても、今のコードの式・減衰しない波・ε の波の誤差の2乗和を並べる。周期ごとの境界の単位の数を野球の 24 単位と並べる。基準にはしない。結果は `results/posthoc_boundary_forms.md`。

## 限界

- 実データは 5 つの出どころの**主食価格**だけ。野球から離れたが、一つの種類のデータ（価格の月次）であることに変わりはない。ほかの種類（物理量、人口、指標）は入っていない
- 窓の長さ・τ・合成の系列は任意の選び方。基準値は野球の値を目安にした
- 窓は互いに重ならないが、同じ系列の窓は独立ではない（同じ国・商品の価格の動きが続く）。窓の数 = 独立な標本の数ではない
- ε の値そのものの選び方（どの n が良いか）は決めない。ここで見るのは、小さな ε の範囲で結果が ε によらないか
