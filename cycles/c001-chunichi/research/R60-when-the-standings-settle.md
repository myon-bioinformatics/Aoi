# R60: 何試合目の順位表で、最後の A・B がおおよそ分かるか（研究計画）

記録: 2026-10-05。計算を始める前に書いた。列（`lock_g`・`lock_x`・`lg_set_lock_x`・`q_wl_1〜4`・`lone_down_n`）はテストを通して push した（d12b16b）。実データでの値は、Actions で `season.jsonl` を作り直すまで見ていない。スクリプト [r60_settle.py](r60_settle.py) も同じく、まだ実行していない。

## 位置づけ（ユーザーの見立て）

- ある試合数 N までの順位表を見れば、最後の A・B がおおよそ分かるはず。CS 出場や中日の4〜6位が決まるまでに絞ったのはそのため（R26・R57）。その N がほしい
- 3/4 の時点で AB の状態（3〜4位）だった51単位は、最後が A か B かほぼ半々（R58）。微分係数が 0 の所から大きくなったか小さくなったかのように、**推移（遷移）の仕方**で見る。増加・減少の傾向、極大・極小、ほかのチームとの比べ（ある期間に中日だけが減っていた、など）。それ自体に意味は求めないが、命題の材料になる
- 先には、その年の推移を非線形の近似（最小誤差）で表し、理想との違いを数学的に読む。集合論で示せたら、他チームでも使える指標かを確かめる。中日特有の指標も、他チームで使える指標も集めたい
- 中日は、上位3つを目指しながら毎年4〜6位にいる。対策を軽々しく言う前に、今の状況を一つずつ示す

## 列

| 列 | 中身 |
|---|---|
| `lock_g` / `lock_x` | 順位表で自分の側（上位半分か否か）が最後と同じになり、その後変わらなくなった日の消化試合数（**N**）と日付の位置 |
| `lg_set_lock_x` | リーグの上位半分の顔ぶれが最後と同じに落ち着いた日の位置 |
| `q_wl_1〜4` | 自分の試合を4つに分けた区間の勝 − 敗（増加・減少の向き） |
| `lone_down_n` | そのリーグで自分だけが負け越した区間の数 |

`clinch_*`（R26）は数の上で決まった日、`lock_*` は実際の順位表が落ち着いた日。

## 読み方（先に決める。記述で、判定はしない）

範囲: 2020年を除く全単位。

1. **N の分布**: `lock_g` の中央値と四分位を A・B 別に。試合数 10 刻みで「その試合数までに落ち着いていた単位の割合」を並べる（刻みは表示のためで、区切りとして使わない）。`lg_set_lock_x` の中央値
2. **中日の B 12年の N**: 年ごとの `lock_g` と、数の上で B が決まった日（`clinch_out_x`）の間の長さ。中日以外の B の N の中央値と並べる
3. **3/4 の時点で AB の状態の51単位**: 最後 A と最後 B で、N（`lock_g`）と、4つの区間の勝 − 敗の符号の並び（例: `+ + − +`）を並べる。最後の区間（`q_wl_4`）の符号で A と B がどれだけ分かれるかを、組の割合で書く
4. **自分だけが負け越した区間**: `lone_down_n ≥ 1` の単位の数と A・B の内訳。中日の年を書く
5. 阪神 2015年・巨人 2017・2018年の N と区間の並び

## 結果（2026-10-05、Actions の実行 `1578234` で作り直した `season.jsonl` に `r60_settle.py` を実行）

### 1. N の分布

- N（順位表で自分の側が最後と同じに落ち着いた消化試合数）: 全体の四分位 **7・40・93**。A は 3・34・91、B は 9・48・94
- その試合数までに落ち着いていた単位の割合: 10試合 28%、40試合 50%、80試合 65%、100試合 78%、120試合 84%、140試合 96%
- リーグの上位半分の顔ぶれが落ち着いた位置の中央値は 0.81（シーズンの8割）
- **半分の単位は40試合までに最後の側に落ち着き、そこから一度も動かない**。残りの半分が、シーズンの後半まで入れ替わる

- 中日の B の N の中央値は 46（中日以外の B は 48）。**落ち着く早さは、ほかの B と変わらない**
- 2017・2021・2023年は、開幕から1〜8試合で B の側に入り、そのまま一度も上の側に出なかった
- 順位表で落ち着いた日と、数の上で B が決まった日の間は、シーズンの 0.22〜0.90。**多くの年で、シーズンの半分以上を「順位表では B のまま、数の上ではまだ決まっていない」状態で戦っていた**

- 2022年（6位）は4区間のうち3区間で勝ち越したが、2つ目の区間の −14 が残った（3, −14, 1, 1）

### 3. 3/4 の時点で AB の状態（3〜4位）の51単位（最後 A 26・B 25）

- N の中央値は 最後 A 108、最後 B 107。どちらも最後の数週間まで落ち着かない
- **最後の区間（4つ目）の勝 − 敗が A の側で大きい組の割合: 0.80**

| 最後の区間 | 最後 A | 最後 B |
|---|---|---|
| 勝ち越し（+） | **16** | 7 |
| 五分（0） | 3 | 1 |
| 負け越し（−） | 7 | **17** |

- 3/4 の時点で AB の状態から、最後の区間の向き（微分係数の符号）で A と B がおおよそ分かれる（16・17 対 7・7）。ユーザーの見立て（0 の所からどちらに動いたか）の形が出た
- 区間の並びは型がばらばらで、同じ並びは多くても3単位

### 4. 自分だけ負け越した区間

4単位だけ（A 1・B 3）。中日はなし。中日の減少は「自分だけ」ではなく、ほかのチームも減っている区間で減っていた

### 5. 阪神 2015年・巨人 2017・2018年

- 阪神 2015年: N **54**（位置 .35）。区間 −5, +7, +6, −9。54試合目から最後まで上の側にいた（3/4 以降の −9 でも落ちなかった）
- 巨人 2017年: N 133、区間 +1, −10, +5, +8。最後の区間で +8 でも届かなかった（表の「+ → B」の7単位の1つ）
- 巨人 2018年: N 141、区間 +2, −8, +3, −1。最後の区間 −1 でも残った

## 読み

- **N はおおよそ40試合**（半分の単位が落ち着く所）。ただし落ち着かない半分は、シーズンの最後の区間まで入れ替わる。その中では、最後の区間の向きが A・B をおおよそ分ける
- 中日の B は、落ち着く早さはほかの B と同じで、年によっては開幕直後から B の側。4区間すべて負け越しが5年あり、この形で A に入った単位は13年間にない（勝ち越しの合計と算術でつながるので、強さの記述として読む）
- 中日は「自分だけが減っていた」区間がない。減るときは、ほかのチームも減っている区間で、より多く減っている

## 種（次の命題へ）

1. **3/4 の時点で3〜4位なら、最後の区間で勝ち越せば A**（P191、結果を見た後。2026年で確かめる）
2. 4区間すべて負け越し ⇒ B（16/16）は勝 − 敗の合計と算術でつながるので命題にしない。代わりに、**落ち着いた後（N 以降）の区間の向き**を見る: 中日は B に落ち着いた後も負け越しを続けたのか、五分に戻したのか
3. 非線形の近似（ユーザーの見立て）: 既にある順位の減衰する波の当てはめ（`wave_*`、R2x）を、N の前と後で分けて当て、近似からのずれを年ごとに並べる
4. 他チームでも使えるか: N と最後の区間の向きは、どのチームにも同じ定義で付く。チームごとに並べて、中日特有か一般的かを見る
